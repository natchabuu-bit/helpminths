# HelpMinths — เครื่องมือตรวจกรอบภาพในเครื่อง

ดาวน์โหลด [HelpMinths-review-tool.zip](https://github.com/natchabuu-bit/helpminths/raw/refs/heads/main/tools/review/HelpMinths-review-tool.zip) แล้วแตก ZIP และเปิด `review.html` ด้วย Chrome หรือ Edge

ZIP นี้มีเฉพาะเครื่องมือและคู่มือ ภาพกล้องจุลทรรศน์ของผู้ใช้ไม่ได้รวมอยู่ในไฟล์ที่เผยแพร่ ให้เลือกภาพต้นฉบับจากเครื่องของตนเอง ภาพจะถูกอ่านในเบราว์เซอร์และไม่อัปโหลดผ่านเครือข่าย

## เริ่มตรวจ 3 ภาพ

1. หากภาพอยู่ใน `helminth original.zip` ให้แตก ZIP ของภาพต้นฉบับก่อน
2. เปิด `review.html` แล้วเลือกไฟล์ภาพให้ตรงกับรายการ Taenia, Hookworm และ OV
3. ซูมดูกรอบ ชื่อกลุ่ม และวัตถุที่อาจตกหล่นทั้งภาพ กรอบตั้งต้นเป็นเพียงร่างสำหรับภาพอ้างอิง 1706 × 960 ต้องตรวจตำแหน่งแม้ความละเอียดเท่ากัน หากขนาดต่างกันจะไม่ใช้กรอบเดิมโดยอัตโนมัติ
4. ให้ผู้ช่วยตรวจยืนยันชื่อ/ขอบกรอบและความครบของวัตถุแต่ละภาพ เว้นสถานะที่ยังยืนยันไม่ได้ไว้ หากแก้กรอบหรือชื่อหลังรับรองต้องตรวจใหม่
5. กดดาวน์โหลด JSON ด้านบน แล้วแนบไฟล์ `.json` กลับในแชต ดาวน์โหลดเป็นร่างได้แม้ยังตรวจไม่ครบ

เปิดหน้าค้างไว้จนบันทึกผลเสร็จ เพราะการปิดหรือรีเฟรชจะล้างงานที่ยังไม่ได้ดาวน์โหลด JSON บันทึกชื่อไฟล์ ขนาดภาพ hash พิกัด และสถานะ ไม่รวมเนื้อภาพ

หากไม่สะดวกส่ง JSON สามารถส่งผลตรวจเป็นข้อความแยกรายภาพได้ โดยระบุชื่อชนิดถูกต้องหรือไม่ กรอบถูกต้องหรือไม่ ตรวจเป้าหมายครบทั้งภาพหรือไม่ และจุดที่ต้องแก้ ทีมพัฒนาสามารถบันทึก annotation จากคำยืนยันจริง พร้อมระบุที่มาว่าเป็นผลตรวจที่ส่งผ่านแชต

## ขอบเขต

เครื่องมือนี้รองรับตรวจและแก้ป้ายกำกับ ไม่มี AI วิเคราะห์หรือฝึกโมเดล ชื่อชนิดตั้งต้นยังไม่ใช่ผลยืนยันจากผู้เชี่ยวชาญ และไม่มีสเกลสำหรับแปลงเป็นไมโครเมตร

คลาสในรอบเริ่มต้น: YOLO 0 = Opisthorchis viverrini, 1 = Hookworm, 2 = Taenia spp. ใช้เฉพาะระดับชื่อที่หลักฐานรองรับ หากไข่ใบไม้คล้าย OV/MIF ยังแยกไม่ได้ ให้เก็บเป็นไม่แน่ชัด; Taenia คงระดับ spp.

ไฟล์เผยแพร่ในโฟลเดอร์นี้เป็นเครื่องมือทั่วไปเท่านั้น ข้อมูลภาพและผลตรวจของผู้ใช้ควรเก็บแยกจาก repository สาธารณะ
