# หลักฐานและขอบเขตการฝึก HelpMinths

ตรวจทบทวนวันที่ 23 ตุลาคม 2569 (2026) เอกสารนี้แยกหลักฐานที่เปิดอ่านจริง
ออกจากแหล่งที่ต้องตรวจต่อ ไม่ใช่รายงานความแม่นยำของโมเดล

## งานรอบแรก: ภาพจริง 3 ภาพ

ผู้ใช้จะเริ่มด้วยภาพกล้องจุลทรรศน์ 3 ภาพพร้อมชื่อพยาธิ และยังไม่ต้องวาดกรอบเอง
อัปเดต 25 ตุลาคม 2569: ได้รับภาพทั้งสามและ JSON ที่ผู้ใช้ส่งกลับเพื่อรับรองชื่อกลุ่ม กรอบ และความครบของวัตถุแล้ว ตรวจ hash ขนาดและการหมุนตรงกับต้นฉบับ เก็บที่มาว่าเป็นคำรับรองที่ผู้ใช้ส่ง ไม่ใช่การตรวจยืนยันอิสระ และเก็บภาพนอก repository สาธารณะ
ไม่มีการฝึกโมเดลจากภาพเหล่านั้น และยังคำนวณความแม่นยำในการตรวจภาพใหม่ไม่ได้

ภาพ 3 ภาพเหมาะสำหรับทดลองขั้นตอนรับภาพ ตรวจคุณภาพ วาดกรอบ และให้ผู้เชี่ยวชาญ
ทบทวนคำตอบ การรู้ชื่อพยาธิระดับภาพเพียงอย่างเดียวไม่บอกตำแหน่งของแต่ละฟอง
และไม่ยืนยันว่าทุกวัตถุในภาพเป็นชนิดเดียวกัน ภาพที่มีหลายฟองหรือมีการติดเชื้อร่วม
ต้องตรวจแต่ละกรอบแยกกัน ไม่ใช้ชื่อภาพเติม label ให้ทุกวัตถุโดยอัตโนมัติ

ข้อมูลที่ควรเก็บกับภาพชุดแรก:

- ไฟล์ต้นฉบับที่ยังไม่ถูกแชตบีบอัด พร้อมชื่อพยาธิที่ผู้ใช้ทราบ
- วิธีทราบชนิด เช่น ผู้ตรวจสไลด์ระบุ หรือผลตรวจยืนยันอื่น พร้อมสถานะว่าใครตรวจแล้ว
- วิธีเตรียมตัวอย่าง กำลังขยาย รุ่นกล้อง/โทรศัพท์ และ scale bar ที่สอบเทียบ หากมี
- รหัสตัวอย่าง/สไลด์แบบไม่ระบุตัวบุคคล เพื่อทราบว่าภาพใดมาจากตัวอย่างเดียวกัน
- สิทธิการใช้ภาพเพื่อพัฒนาโมเดล โดยตัดชื่อและเลขประจำตัวผู้ป่วยออกก่อนส่ง

ขนาดไข่เป็นไมโครเมตรห้ามคำนวณจากจำนวนพิกเซลเมื่อไม่มีมาตราส่วนที่สอบเทียบ
กรอบร่างจากคนหรือ AI ต้องติดสถานะ `draft` จนกว่าผู้ตรวจที่มีความรู้ปรสิตวิทยาจะ
ยืนยันตำแหน่ง ชนิด/กลุ่ม และความครบถ้วนของวัตถุในภาพ

ห้ามนำภาพทั้งสามไปฝึกแล้วทดสอบบนภาพเดิมเพื่ออ้างความแม่นยำ การครอป หมุนภาพ
หรือเพิ่มภาพจำลองจากต้นฉบับเดิมไม่ทำให้ได้ตัวอย่างผู้ป่วยอิสระเพิ่มขึ้น

## ขอบเขตชนิดที่ควรรายงาน

Atlas ปัจจุบันมี 11 กลุ่มไข่ และ **Strongyloides ระยะตัวอ่อน** อีก 1 รายการ
รายการใน Atlas ไม่เท่ากับคลาสที่โมเดลตรวจได้จริง ตารางต่อไปเป็นขอบเขตเสนอสำหรับ
ทำคู่มือ annotation ซึ่งต้องให้ผู้เชี่ยวชาญรับรองก่อนใช้เป็นข้อมูลอ้างอิงทางคลินิก

| เป้าหมายใน Atlas | ชุดข้อมูลผู้สมัครที่พบ | ขอบเขต label และข้อจำกัด |
|---|---|---|
| Ascaris lumbricoides | Chula, LIDS eggs | แยกชนิดออกจากระยะพัฒนาและสภาพ decorticated; ไม่ใช้ภาพนิ่งยืนยันความมีชีวิตหรือความสามารถก่อการติดเชื้อ |
| Trichuris trichiura | Chula, LIDS eggs | ต้องมีตัวอย่างที่เป็นสิ่งรบกวนและไข่มีปลั๊กคล้ายกันเพื่อทดสอบความจำเพาะ |
| Hookworm egg | Chula, LIDS eggs | ใช้ระดับกลุ่ม ไม่แยก Ancylostoma/Necator จากไข่เพียงภาพเดียว; ชื่อ Ancylostoma ใน LIDS ไม่พิสูจน์ความสามารถแยกสกุล |
| Opisthorchis viverrini (OV) | Chula มีชื่อดิบ `Opisthorchis viverrine` | ตรวจพจนานุกรมชื่อ/ground truth ต้นทางก่อนแก้ชื่อ; การแก้การสะกดไม่ใช่การยืนยันชนิด |
| Minute intestinal flukes (MIF) | ยังไม่พบใน config Chula หรือ LIDS ที่อ่าน | เป็นหลายชนิดรวมกัน ต้องรวบรวมภาพจริงและเกณฑ์ยืนยัน; เมื่อแยก OV/MIF ไม่ได้ให้ใช้กลุ่ม `OV/MIF-like` และส่งตรวจยืนยัน |
| Taenia spp. | Chula, LIDS eggs | ไม่รายงาน T. solium/T. saginata จากไข่เพียงอย่างเดียว |
| Enterobius vermicularis | Chula, LIDS eggs | ต้องบันทึกวิธีเก็บตัวอย่างและประเมินกับ workflow ที่จะใช้จริง เช่น เทปกาว ไม่เหมารวมผลจากต่างวิธี |
| Hymenolepis nana | Chula, LIDS eggs | ตรวจ polar filaments และองค์ประกอบอื่นร่วมกัน ภาพเบลอที่ไม่เห็น filament ไม่ใช่หลักฐานว่าขาด filament |
| Hymenolepis diminuta | Chula, LIDS eggs | ต้องมีภาพ/มาตราส่วนและข้อมูลอ้างอิงพอแยกจาก H. nana; ไม่ตัดสินจากขนาดพิกเซลอย่างเดียว |
| Echinostoma spp. | ยังไม่พบใน config Chula หรือ LIDS ที่อ่าน | ไข่พยาธิใบไม้ขนาดใหญ่มีลักษณะทับซ้อน ต้องคงคำตอบระดับกลุ่มเมื่อหลักฐานชนิดไม่พอ |
| Fasciolopsis buski | Chula | ต้องมี Fasciola และไข่ใบไม้อื่นเป็นตัวเปรียบเทียบ; ภาพไข่อย่างเดียวอาจไม่พอแยกชนิด |
| Strongyloides stercoralis | LIDS larvae มีชื่อชนิดนี้ | **ไม่ใช่ไข่**; README ไม่ระบุระยะ rhabditiform/filariform หรือการเห็น genital primordium ต้องตรวจภาพและระยะใหม่ก่อนใช้ label ระยะเฉพาะ |

การฝึก Strongyloides ควรมีตัวอ่อนพยาธิปากขอและสิ่งรบกวนเป็นตัวเปรียบเทียบ
คู่มือ rhabditiform ใช้ช่องปากสั้นและ genital primordium ที่เด่นร่วมกับรูปร่างอื่น
ห้ามนำหางเว้าของระยะ filariform ไปใช้เป็นเกณฑ์ของ rhabditiform
เมื่อภาพไม่เห็นโครงสร้างสำคัญให้เก็บ label ว่าไม่แน่ชัด แทนการบังคับชื่อชนิด/ระยะ

## จากชุดทดลองไปสู่ข้อมูลฝึกที่ใช้ประเมินได้

1. จัดทะเบียนต้นทาง สิทธิ ไฟล์ต้นฉบับ hash ชื่อดิบ วิธีแปลงชื่อ และรุ่น annotation
   แยกใบอนุญาตของ code, images, annotations และ weights ออกจากกัน
2. เพิ่มภาพเต็มจากอุปกรณ์และวิธีเตรียมตัวอย่างที่ต้องการใช้จริง รวมภาพลบจริง
   เชื้อร่วม ไข่น้อย ภาพเบลอ แสงผิด เศษพืช ฟองอากาศ และพยาธินอกขอบเขต
   การใช้ภาพสวยที่มีไข่ตรงกลางอย่างเดียวไม่ครอบคลุมงานอัปโหลดจริง
3. ให้ผู้ตรวจที่มีความรู้ 2 คนตรวจอย่างอิสระ และมีผู้ตัดสินเมื่อเห็นต่าง เก็บ label
   ไม่แน่ชัด/คุณภาพไม่พอไว้ ไม่บังคับทุกกรอบให้เป็นหนึ่งในชื่อพยาธิที่ตั้งไว้
4. การตรวจยืนยันระดับสิ่งส่งตรวจ เช่น molecular test ใช้ช่วย ground truth ได้
   แต่ไม่ได้ระบุชนิดของไข่แต่ละฟองโดยอัตโนมัติเมื่อมีการติดเชื้อร่วม
5. แบ่งชุดตามผู้ป่วย/สิ่งส่งตรวจ/สไลด์ก่อนสร้าง crop หรือ augmentation
   ภาพซ้ำ ภาพต่างโฟกัสของจุดเดิม และภาพที่มาจากต้นฉบับเดียวกันต้องอยู่กลุ่มเดียว
   หากไม่มีรหัสกลุ่มจากชุดสาธารณะ ให้ระบุข้อจำกัด ไม่อ้างว่า split ปลอด leakage
6. แยก external test จากหน่วยบริการ/อุปกรณ์/ช่วงเวลาที่ไม่ได้ใช้พัฒนาโมเดล
   ล็อกชุดนี้ไว้และไม่ใช้ปรับ threshold หลังดูคำตอบแล้ว เวอร์ชัน mirror ของ
   ชุดเดิมไม่ถือเป็น external test ใหม่

ข้อมูล 3 ภาพเป็นจุดเริ่มสร้างคู่มือและทดลอง annotation ไม่ใช่ขนาดตัวอย่างเพื่อ
ฝึกหรือยืนยันประสิทธิภาพของ 12 เป้าหมาย เมื่อทดลองได้แล้วจึงวางแผนเก็บข้อมูล
กับอาจารย์/ห้องปฏิบัติการ โดยคำนวณขนาดชุดทดสอบจากความแม่นที่ต้องการและ
ความไม่แน่นอนที่ยอมรับ ไม่รับประกันผลจากจำนวนภาพหรือจำนวน epoch ตายตัว

## สิ่งที่ต้องวัดก่อนบอกผู้ใช้ว่า “ตรวจได้จริง”

- ระดับวัตถุ: sensitivity/recall และ precision ต่อชนิด พร้อมเกณฑ์จับคู่กรอบ
  และ mAP ที่ใช้ระบุไว้ล่วงหน้า จำนวนไข่ที่นับซ้ำหรือพลาดต้องรวมในผล
- ระดับภาพ: false positives ต่อภาพ/field และผลในภาพลบจริง รวมกลุ่มคุณภาพต่ำ
- ระดับตัวอย่าง/ผู้ป่วย: sensitivity, specificity, PPV, NPV พร้อมช่วงความเชื่อมั่น
  95% จำนวนตัวอย่างแต่ละกลุ่ม และความชุกของชุดทดสอบ PPV/NPV เปลี่ยนตามความชุก
- รายงานผลแยกอุปกรณ์ วิธีเตรียมตัวอย่าง ชนิด ระยะ และภาระพยาธิ รวมผลของการ
  ขอถ่ายใหม่/ส่งผู้เชี่ยวชาญ จำนวนที่ระบบงดตอบต้องแสดงด้วย ห้ามซ่อนจากตัวหาร
- ใช้การประเมินความไม่แน่นอนตามผู้ป่วย/สไลด์ เช่น grouped bootstrap เมื่อภาพ
  หลายภาพสัมพันธ์กัน ไม่ถือว่าไข่หลายฟองจากสไลด์เดียวเป็นผู้ป่วยอิสระหลายราย

คะแนน confidence ของโมเดลไม่ใช่ความน่าจะเป็นว่าผู้ป่วยติดเชื้อ และการไม่พบไข่
ในภาพเดียวไม่ใช่ผลลบของการตรวจอุจจาระทั้งตัวอย่าง
หน้าผลลัพธ์ควรระบุว่าเป็นผลช่วยคัดกรองจากภาพ ระดับชื่อที่หลักฐานรองรับ
และเหตุผลเมื่อจำเป็นต้องถ่ายใหม่หรือให้ผู้เชี่ยวชาญตรวจยืนยัน
