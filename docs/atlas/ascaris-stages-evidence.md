# หลักฐานสำหรับระยะไข่ Ascaris ใน Atlas

ตรวจแหล่งข้อมูล 20 ตุลาคม 2569 (2026) สำหรับสื่อการเรียนรู้ของ
*Ascaris lumbricoides* ไม่ใช่การฝึกหรือการตรวจยืนยันความแม่นยำ AI

## การจัดหัวข้อที่ถูกต้อง

แยกสถานะการปฏิสนธิและการพัฒนาออกจากสภาพผิวเปลือก:

| หัวข้อ | สิ่งที่ภาพจำลองควรสื่อ | ความหมายด้านระยะติดต่อ |
|---|---|---|
| ไข่ไม่ปฏิสนธิ — Unfertilized egg | มักยาวกว่า เปลือกค่อนข้างบางกว่า มีเนื้อหาเป็นเม็ดไม่สม่ำเสมอ | ไม่พัฒนาต่อเป็นไข่ที่มีตัวอ่อนระยะติดต่อ ไม่วาดลูกศรต่อไปเป็นไข่ปฏิสนธิ |
| ไข่ปฏิสนธิระยะต้น — Fertilized, unembryonated egg | รูปรี/ค่อนข้างกลม เปลือกหนา มวลเซลล์ไข่ที่ยังไม่แบ่ง | ไข่ปฏิสนธิที่เพิ่งขับออกมากับอุจจาระยังไม่ใช่ระยะติดต่อ |
| ระยะแบ่งเซลล์ — Cleavage stage | เซลล์แบ่งเป็น 2, 4 หรือหลายเซลล์ภายในเปลือก เป็นขั้นพัฒนาต่อของไข่ปฏิสนธิ | การเห็นเซลล์แบ่งตัวเพียงอย่างเดียวไม่ใช่หลักฐานว่าเป็นไข่ระยะติดต่อ จำนวนที่วาดเป็นตัวอย่างเพื่ออธิบาย |
| ไข่มีตัวอ่อนพัฒนาสมบูรณ์ — Mature embryonated/larvated egg | มีตัวอ่อนขดอยู่ภายในไข่ | เป็นระยะที่เกี่ยวข้องกับการติดต่อทางการกินเมื่อมีตัวอ่อนพัฒนาสมบูรณ์และยังมีชีวิต ภาพนิ่งเพียงภาพเดียวไม่พิสูจน์ความมีชีวิตหรือความสามารถก่อการติดเชื้อ |
| ไข่เปลือกชั้นนอกหลุด — Decorticated egg | ไม่มีชั้นผิวขรุขระ mammillated coat แต่ยังมีเปลือกไข่ชั้นที่เหลือ | เป็นสภาพของชั้นผิว ไม่ใช่ระยะที่ต้องเกิดหลัง embryonated เสมอ และไม่ยืนยันความเป็นระยะติดต่อ พบได้ในไข่ปฏิสนธิและไม่ปฏิสนธิ |

เส้นทางพัฒนาที่แสดงเป็นภาพอธิบายได้คือ **ไข่ปฏิสนธิระยะต้น → แบ่งเซลล์ →
มีตัวอ่อนพัฒนาสมบูรณ์** ส่วนไข่ไม่ปฏิสนธิเป็นอีกแขนงหนึ่ง และ decortication
เป็นสถานะของชั้นผิวที่แยกออกจากเส้นทางนั้น

ไม่ใส่ระยะตัวอ่อนเป็น L2/L3 ในสื่อรอบนี้ เพราะศัพท์และหลักฐานที่เข้าถึงไม่ได้
เพียงพอสำหรับยืนยัน instar จำเพาะ และไม่ได้กำหนดจำนวนวันตายตัวเป็นเกณฑ์
ระยะติดต่อ การพัฒนาขึ้นกับสภาพแวดล้อมและความมีชีวิตของไข่

## ภาพที่ยังไม่มีหลักฐานเพียงพอสำหรับเพิ่มเป็นภาพกล้องจริง

- คลัง Buckelew ไม่มีไฟล์หรือคำบรรยาย Ascaris ระยะ cleavage หรือ decorticated
  ที่ตรวจยืนยันได้ ภาพ mixed-fertilized ไม่ได้ระบุจำนวนเซลล์ จึงไม่เปลี่ยนชื่อ
  เป็น cleavage เพียงเพราะเห็นเนื้อหาภายใน
- พบ `Skhawari/ascaris-stage-segmentation` ที่ระบุชัดว่าเป็น **Ascaris suum**
  จึงไม่ใช้รูปหรือชื่อระยะจากโครงการนั้นมาเปลี่ยนชื่อเป็น A. lumbricoides
- พบ `Joryuoo/AgarthaVision-Desktop` กล่าวถึง decorticated ในแผนฟีเจอร์
  แต่ไม่ใช่แหล่งภาพปรสิตวิทยาที่ตรวจชนิด/สิทธิ์และไม่ใช่หลักฐานชีววิทยาปฐมภูมิ
- `CriddleLab/AscarisMicroscopy` เป็น code-base สำหรับตรวจนับไข่ ไม่มีข้อมูล
  คำบรรยายและสิทธิ์ที่ยืนยันภาพ cleavage/decorticated ได้จาก README ที่เข้าถึง

ภาพประกอบแต่ละระยะจึงควรเป็น **ภาพวาดจำลองที่ระบุชนิดสื่อชัดเจน** เมื่อยัง
ไม่มีภาพกล้องจริงที่ตรวจชนิด ระยะ และสิทธิ์ครบ และใช้ภาพจริงสองไฟล์เดิมตาม
คำบรรยายที่ตรงกับภาพเท่านั้น ภาพวาดไม่ควรเลียนแบบเป็นภาพกล้องจุลทรรศน์
หรืออ้างว่าได้วัดขนาด ความหนา หรือออร์แกเนลล์ของไข่จริงจากรูปนั้น
