# Dashboard โครงการ กพด. เขตสุขภาพที่ 2

หน้า `/#dashboard` แสดงสถิติสรุปจาก Google Sheets ที่เจ้าของโครงการระบุ ผู้เข้าเว็บทุกคนดูได้ตามคำขอ ไม่ต้องเปิดฐานข้อมูล HelpMinths และไม่ส่งข้อมูลกลับไปแก้ไขชีต

แหล่งข้อมูลที่ตั้งไว้คือ [Google Sheets ของโครงการ](https://docs.google.com/spreadsheets/d/1OlVnkehNCAJWVE0sR_5ypqi9XeuCI8-d/edit) ส่วน Dashboard จากฐานข้อมูลการตรวจ AI เดิมยังอยู่หน้าแรกและใช้สิทธิ์บัญชีเดิม ตัวเลขทั้งสองแหล่งแยกจากกัน

## สถานะที่ยืนยันได้

พัฒนาเมนู ตัวเชื่อม การรวมยอด และระบบอัปเดตอัตโนมัติแล้ว ทดสอบด้วยตารางสังเคราะห์ใน automated tests เท่านั้น ยังอ่านแถวข้อมูลจริงจาก Google ไม่สำเร็จในสภาพแวดล้อมนี้: เครือข่ายตอบ `403 Forbidden` ตั้งแต่เชื่อมต่อโดเมน Google จึงยังยืนยันไม่ได้ว่าชีตแชร์อ่านได้หรือไม่ หรือมีแท็บใดบ้าง

เครื่องมือ Spreadsheets และเทมเพลต Analytics Dashboard ที่แนบมาไม่มีให้เรียกในเซสชันนี้ หน้าจอที่สร้างใช้รูปแบบการ์ดสถิติและกราฟโทนสว่างของ HelpMinths ไม่อ้างว่าได้เปิดหรือใช้ไฟล์เทมเพลตนั้นแล้ว

หน้าเว็บแสดงขีด — และข้อความอ่านข้อมูลไม่ได้เมื่อเชื่อมต่อไม่สำเร็จ ไม่มีตัวเลขตัวอย่างใน production การได้ HTTP200 จาก API ของแอพไม่แปลว่าอ่าน Google สำเร็จ ต้องตรวจ `status`, `fetched_at` และ `error` ในผลตอบกลับด้วย

## วิธีคำนวณและตรวจยอด

- นักเรียนทั้งหมด / ส่งตรวจ / ตรวจพบ: รวมคอลัมน์4 / 5 / 7 ตามลำดับจากแถวโรงเรียนที่เลือก
- ร้อยละส่งตรวจ = ผลรวมส่งตรวจ ÷ ผลรวมนักเรียนทั้งหมด ×100
- ร้อยละตรวจพบ = ผลรวมตรวจพบ ÷ ผลรวมส่งตรวจ ×100
- ไม่เฉลี่ยร้อยละรายโรงเรียน เพราะแต่ละโรงเรียนมีตัวหารต่างกัน และไม่ใช้ร้อยละต้นทางแทนยอดที่คำนวณจากจำนวนจริง
- จำนวนติดมากกว่า1ชนิดมาจากคอลัมน์25 แสดงแยกจากกลุ่มพยาธิ8กลุ่ม ไม่บวกผลรายชนิดเป็นจำนวนผู้ติดเชื้อไม่ซ้ำ
- แยกแถวรวมออกก่อนรวมยอด โดยคงชื่อโรงเรียนจริงที่มีคำว่า "รวม" เช่น "รวมไทยพัฒนา1"
- ชื่อโรงเรียนและพื้นที่ใช้ตรวจแถวซ้ำภายในเซิร์ฟเวอร์ เก็บสระ/วรรณยุกต์ไทยไว้เพื่อไม่รวมคนละโรงเรียนเข้าด้วยกัน แถวซ้ำที่ตัวเลขตรงกันนับครั้งเดียว แถวซ้ำที่ยอดขัดกันต้องตรวจทานและไม่ใช้ยอดที่คลุมเครือ
- ช่องว่าง ขีด ตัวเลขลบ จำนวนคนไม่เป็นจำนวนเต็ม หรือยอดส่งตรวจมากกว่านักเรียน/ผลบวกมากกว่าผู้ตรวจ จะไม่ถูกแทนเป็นศูนย์ บางยอดจึงอาจเป็น — พร้อมคำอธิบาย
- ไม่สร้างปีข้อมูลเมื่อหัวตารางไม่ระบุปี ตัวกรองปีเปิดเมื่อมีคอลัมน์ปี/วันที่ที่อ่านได้จริงเท่านั้น

ตัวเลขนี้เป็นผลในกลุ่มที่ส่งตรวจตามแหล่งข้อมูล ไม่ได้ยืนยันความชุกของประชากรทั้งหมด และไม่ใช่ผลการตรวจหรือความแม่นยำจากโมเดล HelpMinths

## การอัปเดตและการเผยแพร่

หน้าเว็บอ่าน API อัตโนมัติทุก30วินาทีหลังคำขอก่อนหน้าจบ หยุดเมื่อแท็บซ่อนหรือเครื่องออฟไลน์ และอ่านใหม่เมื่อกลับมาใช้งาน เซิร์ฟเวอร์ใช้ cache ร่วมต่อ process เพื่อไม่ให้แต่ละผู้ชมยิง Google ซ้ำ บัญชี/แท็บ/โครงสร้างที่เปลี่ยนจะไม่ใช้ cache แหล่งเก่า

"ดึงข้อมูลล่าสุด" คือเวลาที่อ่านและแปลงข้อมูลสำเร็จ ไม่ใช่เวลาที่เจ้าของแก้ไขชีต หาก Google ขัดข้องหลังเคยสำเร็จ จะแสดงสถิติครั้งก่อนพร้อมข้อความข้อมูลอาจไม่เป็นปัจจุบันและเวลาเดิม ปุ่มรีเฟรชยังเคารพรอบ cache จึงไม่รับประกันว่าจะส่งคำขอใหม่ไป Google ก่อนครบช่วงที่กำหนด

นี่เป็นการดึงข้อมูลเป็นระยะ ไม่ใช่การรับทุกการแก้ไขของ Google Sheets ในทันที ไม่มีการเก็บผล API ไว้ใน service-worker cache ออฟไลน์

API ส่งเฉพาะตัวเลขรวม กลุ่มพยาธิที่รองรับ และจังหวัดในเขตสุขภาพที่2 ไม่คืนชื่อโรงเรียน ตำบล อำเภอ สังกัด ชื่อบุคคล หรือแถวต้นทาง ตัวอ่านและ cache อยู่ฝั่งเซิร์ฟเวอร์ ไม่มี credentials ใน JavaScript

## Configuration

ตั้ง environment ก่อนเริ่ม API ไม่อ่าน `.env` อัตโนมัติ ดู `.env.example`:

| Variable | ค่าเริ่มต้น / หน้าที่ |
| --- | --- |
| `HELPMINTHS_SHEETS_ENABLED` | `1` เปิดตัวเชื่อม; ตั้ง0เพื่อหยุด |
| `HELPMINTHS_SHEETS_ID` | IDของชีตที่เจ้าของระบุ |
| `HELPMINTHS_SHEETS_GID` | `0` เลขแท็บสำหรับ CSV; เปลี่ยนให้ตรงกับ `gid` ใน URLของแท็บจริง |
| `HELPMINTHS_SHEETS_FORMAT` | `auto` ลอง CSV ก่อนแล้วอ่านไฟล์ Excel IDเดิมเมื่อ export ไม่รองรับ; เลือก `csv` หรือ `xlsx` โดยตรงได้ |
| `HELPMINTHS_SHEETS_WORKSHEET` | ว่าง; ชื่อแท็บเมื่อเลือกผ่านชื่อหรือใช้ service account |
| `HELPMINTHS_SHEETS_REFRESH_SECONDS` | `30` ช่วง15–300วินาที |
| `HELPMINTHS_SHEETS_PUBLIC_AGGREGATES` | เมื่อว่าง ชีตโครงการที่ระบุเผยแพร่สรุปได้ ส่วน IDอื่นต้องเข้าสู่ระบบ; ตั้ง1เมื่ออนุญาตเผยแพร่สรุปของแหล่งนั้นจริง |
| `HELPMINTHS_SHEETS_COLUMN_MAPPING` | `{}` ใช้ preset เมื่อหัวตารางตรง; รองรับ mapping สำหรับโครงสร้างอื่นที่ผู้ดูแลตรวจแล้ว |
| `HELPMINTHS_GOOGLE_SERVICE_ACCOUNT_JSON` | ว่าง; JSONบัญชีบริการสำหรับชีตส่วนตัว เก็บเป็น secret ของโฮสต์ |

ตัวอ่านจำกัดข้อมูล5MB, 10,000แถว และ200คอลัมน์ ตัวอ่าน Excel จำกัดขนาดที่ขยายแล้ว50MB/2000รายการภายใน ZIP อ่านเฉพาะค่าที่บันทึกไว้ ไม่รันสูตร macro หรือ external links; สูตรที่ไม่มี cached value จะไม่ถูกเดาเป็นตัวเลข ตั้ง timeout และไม่ส่ง bearer token ตาม redirect ไปเว็บอื่น ไม่มีพารามิเตอร์ให้ผู้ชมกำหนด URLต้นทางหรือส่ง credentials มาทางหน้าเว็บ

### ชีตอ่านได้โดยไม่มีบัญชี

โหมด CSV ใช้ Python standard library ส่วนไฟล์ Excel (.xlsx) ใช้ openpyxl ที่รวมใน dependencies หลัก ตั้ง ID/GID ให้ตรงกับชีตและแท็บสรุปที่อ่านได้อยู่แล้ว สำหรับ Excel เลือกชื่อแท็บด้วย WORKSHEET หรือใช้แท็บแรก การอนุญาตให้ดูสรุปบน HelpMinths ไม่ได้เปลี่ยนสิทธิ์แชร์ของ Google Sheet อัตโนมัติ

### ชีตส่วนตัว

1. สร้าง service account ใน Google Cloud และเปิด Google Sheets API สำหรับชีตปกติ หรือ Google Drive API สำหรับไฟล์ Excel
2. ให้สิทธิ์ Viewer เฉพาะชีตที่ต้องอ่านแก่ email ของ service account
3. ติดตั้ง runtime เพิ่มเติมก่อน build/deploy:

```bash
.venv/bin/python -m pip install -r backend/requirements-sheets.txt
```

4. ตั้ง `HELPMINTHS_GOOGLE_SERVICE_ACCOUNT_JSON` เป็น secret ในโฮสต์ และกำหนดชื่อแท็บที่ถูกต้องถ้าต้องการเลือกแท็บอื่นจากแท็บแรก
5. Restart/deploy แล้วตรวจ API ทั้งสองพาธด้านล่าง

Dockerfile ปัจจุบันติดตั้ง `requirements.lock` เท่านั้น หากใช้ service account ต้องสร้าง image ที่ติดตั้ง `requirements-sheets.txt` เพิ่มด้วย อย่าส่ง private key มาทางแชตหรือใส่ใน Git ตัวเชื่อมใช้ `spreadsheets.readonly` สำหรับชีตปกติ และ `drive.readonly` เฉพาะเมื่ออ่านไฟล์ Excel ไม่มีคำสั่งแก้ไขไฟล์หรือชีต

ลิงก์ที่เปิด Excel ผ่าน Google Sheets รองรับการอ่านไฟล์เดิมโดยไม่แปลงไฟล์ โหมด auto ใช้การอ่าน IDเดิมผ่านช่องทาง Google Drive หาก CSV export ไม่รองรับ การอ่านยังต้องมีสิทธิ์ของต้นทางและเครือข่ายที่เข้าถึง Google ได้ หากการตรวจชนิดไฟล์ไม่ตรง ให้กำหนด FORMAT=xlsx และชื่อ WORKSHEET ที่ถูกต้อง ไม่เปลี่ยนสิทธิ์แชร์หรือแปลงไฟล์ต้นทางโดยอัตโนมัติ

## API และทดสอบ

- `GET /api/platform/operations/status`: สถานะ configuration และแหล่งข้อมูล ไม่มีการอ่านแถวต้นทาง
- `GET /api/platform/operations/dashboard`: สรุปและสถานะการดึงข้อมูล รองรับ `province`, `year`, `from_date`, `to_date`, `status`

```bash
.venv/bin/python -m pytest -q backend/tests/test_sheets_dashboard.py
npm run build
# เปิด production server ตามคู่มือหลักก่อน
HELPMINTHS_TEST_URL=http://127.0.0.1:8081 npm run test:health-dashboard
```

Tests ใช้ชื่อและตัวเลขสังเคราะห์เฉพาะใน fixtures ไม่ใช่ข้อมูลผู้ป่วยหรือผลโครงการ หน้าเว็บจริงต้องไม่มีตัวเลขเหล่านี้ ผลที่รันจริงบันทึกใน `docs/platform/VALIDATION.md`

ก่อนใช้งานสดต้องตรวจยอดรวมเทียบชีตจริงและยืนยันการจัดเก็บ/ไม่ซ้ำของแถวตามหน่วยงาน เมื่อ source อ่านไม่ได้ให้ตรวจเครือข่าย สิทธิ์ ชนิดไฟล์ และแท็บจริง ไม่เติมข้อมูลตัวอย่างแทน
