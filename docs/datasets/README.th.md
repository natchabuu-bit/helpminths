# HelpMinths: แหล่งข้อมูลไข่พยาธิสำหรับพัฒนาโมเดลตรวจจับ

วันที่ปรับขอบเขต: 19 ตุลาคม 2569 (2026) • วัตถุประสงค์: คัดเลือกข้อมูลวิจัยเพื่อฝึกโมเดลที่แสดงกรอบและจำแนกไข่พยาธิบนภาพกล้องจุลทรรศน์จริง

## ขอบเขตปัจจุบันและข้อเสนอ

**ใช้ 11 กลุ่ม: Ascaris lumbricoides, Trichuris trichiura, Hookworm, Opisthorchis viverrini (OV), Taenia spp., Enterobius vermicularis, พยาธิใบไม้ลำไส้ขนาดเล็ก (MIF), Hymenolepis nana (ตืดแคระ), Hymenolepis diminuta (ตืดหนู), Echinostoma spp. และ Fasciolopsis buski** โดยเพิ่ม 5 กลุ่มหลังจากขอบเขตเดิม 6 กลุ่ม ใช้ Echinostoma spp. เป็นตัวอย่างอ้างอิงใบไม้ลำไส้ขนาดกลาง และ F. buski เป็นใบไม้ลำไส้ขนาดใหญ่ คำว่าขนาดกลาง/ใหญ่กล่าวถึงกลุ่มตัวเต็มวัย ไม่ใช่เกณฑ์ขนาดไข่สากลหรือข้ออ้างว่าครอบคลุมทุกชนิดในกลุ่มนั้น

ยังพัก S. mansoni, S. haematobium และ S. japonicum จาก Atlas/การฝึกระยะนี้ตามขอบเขตโครงการ เก็บหลักฐานชุดข้อมูลเดิมในส่วนเอกสารย้อนหลัง การเลือกนี้ไม่ใช่ข้อสรุปว่า Schistosoma ไม่มีในไทยหรือไม่มีความสำคัญทางคลินิก

**เริ่มตรวจ Chula-ParasiteEgg-11 ซึ่งมีชื่อคลาส candidate 9/11 กลุ่ม รวม OV, H. nana, H. diminuta และ F. buski เสริม LIDS–UNICAMP สำหรับ 7/11 กลุ่มและสิ่งรบกวน แล้วเพิ่มภาพเต็มจากห้องปฏิบัติการและโทรศัพท์ที่จะใช้จริงในไทย** โดยยังขาดแหล่งที่ยืนยันภาพ/annotation/สิทธิ์สำหรับ MIF และ Echinostoma ในรอบนี้ และยังไม่มีชุดใดที่ยืนยันสิทธิ์และ provenance ครบเพื่อฝึกและอ้างความแม่นยำทางคลินิกได้ทันที

รายการนี้เป็นแผนข้อมูล ไม่ใช่รายชื่อคลาสที่ AI ของ HelpMinths ตรวจได้แล้ว **ยังไม่ได้ฝึกหรือทดสอบโมเดลใหม่** การมี GitHub สาธารณะหรือ license ของโค้ดไม่ได้ยืนยันสิทธิ์ภาพ/annotation/weights ต้องขอสิทธิ์ฝึกและนำโมเดลขึ้นบริการก่อนใช้จริง แหล่งในขอบเขตยังมีสถานะ `rights/provenance_pending`; แหล่งที่พักไว้ใช้สถานะ `archived_out_of_current_scope` โดยเก็บข้อมูลสิทธิ์แยกต่างหากใน CSV

## 2. กลุ่มที่เพิ่มและเกณฑ์ยืนยันไข่คล้ายกัน

### 2.1 OV และ MIF

**OV หมายถึง Opisthorchis viverrini (พยาธิใบไม้ตับ)** ไม่ใช่ชื่อรวมของไข่พยาธิใบไม้ทุกชนิด Chula มีชื่อคลาสที่ใช้เริ่มตรวจสอบได้ แต่ต้องขอภาพต้นฉบับ กรอบ ข้อมูลวิธียืนยันชนิด และสิทธิ์ก่อนใช้ฝึก โมเดลที่จำชื่อคลาสจาก dataset ได้ไม่ได้ยืนยันว่าจะแยกไข่คล้ายกันจากงานจริงได้

- เก็บภาพอุจจาระเต็ม field จากวิธีเตรียมและอุปกรณ์เป้าหมายในไทย มีหลายความเข้มข้น โฟกัส/แสง การติดเชื้อร่วม ภาพไม่พบไข่ และภาพคุณภาพต่ำ
- เพิ่ม **MIF (Minute Intestinal Flukes)** เป็นกลุ่มเป้าหมาย ไม่ใช่ชื่อพยาธิชนิดเดียว ต้องกำหนดใน data dictionary ว่ารวมชนิดใด เช่น กลุ่ม Haplorchis/heterophyid ที่ห้องปฏิบัติการอ้างอิงยืนยันได้ รวมทั้งเก็บ Clonorchis และไข่อื่นที่คล้ายกันไว้เป็นข้อมูลแยกโรค ห้าม map label ทั่วไปว่า “small fluke egg” เป็น MIF ที่ยืนยันแล้วโดยอัตโนมัติ
- ให้ผู้เชี่ยวชาญประเมินความแยก OV/MIF จากภาพจริง ห้ามติดป้าย OV หรือ MIF จากขนาด รูปร่าง หรือภูมิศาสตร์เพียงอย่างเดียว และไม่ติดป้ายไข่นอกเป้าหมายว่า “ไม่มีไข่พยาธิ”
- วาง reference standard ร่วมกับห้องปฏิบัติการอ้างอิง เช่น หลักฐานโมเลกุลที่เชื่อมกับสิ่งส่งตรวจเมื่อเหมาะสม พร้อมการอ่านโดยผู้เชี่ยวชาญ ผลระดับสิ่งส่งตรวจอย่างเดียวไม่ยืนยันชนิดไข่แต่ละฟองในภาพเมื่อมีการติดเชื้อร่วม
- ถ้าหลักฐานยังแยกไม่ได้ ให้ annotation/ผลต้นแบบระบุ **ไข่ลักษณะคล้าย OV/MIF (OV/MIF-like) / ต้องยืนยันเพิ่ม** แยกจาก OV และ MIF ที่ยืนยันแล้ว และให้มนุษย์ทบทวน ไม่สร้าง ground truth ด้วยการเดาจากภาพ ไม่รายงาน species certainty เกินหลักฐาน
- แยกวัด false positives ระหว่าง OV, MIF และไข่คล้ายกัน รวม confusion matrix และประเมิน recall ในภาพไข่น้อย ก่อนเปิดใช้เป็นคลาสตรวจจริง

[CDC DPDx — Opisthorchiasis](https://www.cdc.gov/dpdx/opisthorchiasis/index.html) เป็นแหล่งอ้างอิง morphology สำหรับผู้เชี่ยวชาญตรวจต่อ ไม่ใช่ dataset ฝึกที่ยืนยันสิทธิ์แล้ว หน้า CDC ยังไม่ได้ตรวจสดสำเร็จจากเครือข่ายคลาวด์รอบนี้ จึงไม่ถือว่าทุกข้อข้างต้นได้รับการยืนยันจากหน้านั้นในการตรวจครั้งนี้

### 2.2 ตืดแคระและตืดหนู

Chula มีชื่อคลาส `Hymenolepis nana` และ `Hymenolepis diminuta` ขณะที่ LIDS มีภาพ 348 และ 80 ภาพตามลำดับ จึงมีจุดเริ่มต้นที่ตรวจหลักฐานชื่อคลาส/จำนวนภาพได้ แต่ยังต้องตรวจสิทธิ์ ภาพเต็ม กรอบรายฟองและความถูกต้องของ label ก่อนฝึก จุดสังเกตอ้างอิงคือ **polar filaments ของ H. nana** และ **การไม่มี polar filaments ของ H. diminuta** ร่วมกับลักษณะเยื่อหุ้มและขนาดที่วัดด้วยเครื่องมือสอบเทียบ ไม่ใช้การมองไม่เห็นเส้นในภาพเบลอเป็นหลักฐานว่าเป็นตืดหนู ต้องมีตัวอย่างโฟกัสหลายระยะและกลุ่มไม่แน่ใจ

[CDC DPDx — Hymenolepiasis](https://www.cdc.gov/dpdx/hymenolepiasis/index.html) เป็นจุดตรวจ morphology เพิ่มเติม ไม่ใช่สิทธิ์ใช้ภาพฝึกที่ได้รับแล้ว และยังไม่ได้ตรวจหน้าเว็บสดสำเร็จในเครือข่ายนี้

### 2.3 ใบไม้ลำไส้ขนาดกลางและใหญ่

ใช้ **Echinostoma spp.** เป็นตัวอย่างอ้างอิงกลุ่มใบไม้ลำไส้ขนาดกลาง และ **Fasciolopsis buski** เป็นใบไม้ลำไส้ขนาดใหญ่ใน Atlas ตามขอบเขตครั้งนี้ ไม่ตีความว่าขนาดไข่จัดกลุ่มตัวเต็มวัยได้แน่นอน หรือว่า reference สองรายการนี้ครอบคลุมพยาธิใบไม้ลำไส้ทุกชนิด Chula มีชื่อคลาส F. buski แต่ **ยังไม่พบ MIF/Echinostoma ใน configuration ที่ตรวจ และยังไม่มีแหล่งภาพไข่สองกลุ่มนี้ที่ยืนยันต้นทาง annotation และสิทธิ์ครบในทะเบียนรอบนี้** ต้องหาห้องปฏิบัติการที่มีสิ่งส่งตรวจยืนยันและขอเก็บภาพอย่างเป็นระบบต่อ

ไข่ **Echinostoma/Fasciolopsis/Fasciola** อาจมีขนาดและรูปร่างทับซ้อนกัน โดยเฉพาะภาพที่ไม่มีสเกลหรือเตรียมต่างวิธี ต้องบันทึกวิธียืนยันที่เชื่อมกับไข่/สิ่งส่งตรวจจริงและให้ผู้เชี่ยวชาญทบทวน หากแยกไม่ได้ให้ใช้กลุ่มไข่มีฝาปิดที่ยังไม่ยืนยันและไม่ฝืนใส่ชื่อชนิด **Fasciola เป็นพยาธิใบไม้ตับ จึงไม่ map ชื่อนี้เป็น F. buski หรือใบไม้ลำไส้ขนาดใหญ่** และไม่ใช้ลักษณะ adult collar spines ของ Echinostoma เป็นลักษณะของไข่

จุดตรวจอ้างอิงเพิ่มเติม: [CDC DPDx — Echinostomiasis](https://www.cdc.gov/dpdx/echinostomiasis/index.html), [Fasciolopsiasis](https://www.cdc.gov/dpdx/fasciolopsiasis/index.html) และ [Fascioliasis](https://www.cdc.gov/dpdx/fascioliasis/index.html) ยังไม่ได้ตรวจหน้าเว็บสดสำเร็จและยังไม่ได้รับสิทธิ์ภาพฝึกจากลิงก์เหล่านี้

### 4.1 S. mansoni แบบ Kato–Katz จากกลุ่ม UFMG — ชุดงานวิจัยต้นทางขนาดเล็ก

- ผู้เขียนและโค้ด: [detection-eggs-schisto](https://github.com/brunoalbertobambui/detection-eggs-schisto)
- ต้นทางข้อมูลที่ README ผู้เขียนเชื่อมโดยตรง: [Mendeley Data version 2](https://data.mendeley.com/datasets/5ckgmp4zzj/2)
- งานต้นฉบับ: [Automated Diagnosis of Schistosomiasis… Kato-Katz Technique](https://doi.org/10.1007/s00521-022-06924-z)
- README ยืนยัน **66 ภาพจริง** ของ S. mansoni เตรียมด้วย Kato–Katz งานใช้ Faster R-CNN ตรวจกรอบไข่; ไม่ได้ยืนยันจำนวนผู้ป่วย สไลด์ ไข่ทั้งหมด หรือรูปแบบ annotation ในไฟล์ฝากข้อมูล
- ผู้เขียนมีสังกัด UFMG ประเทศบราซิล รวมภาควิชาปรสิตวิทยา แต่ยังไม่ยืนยันสถานที่เก็บสิ่งส่งตรวจจาก README
- หากขยายเป้าหมายกลับมาในอนาคต อาจเสริมสภาพภาพอุจจาระและเป็นชุดทดลองต่างแหล่งหลังตรวจการซ้ำ/สิทธิ์ **ขนาดเล็กเกินกว่าจะเป็นฐานฝึกเพียงชุดเดียว** ตัวเลข AP ในงานเป็นผลเฉพาะการทดลองของผู้เขียน ไม่ใช่ความแม่นยำของ HelpMinths

Mendeley และบทความต้นทางถูกจำกัดการเข้าถึงจากเครือข่ายนี้ จึงยังไม่ได้อ่าน license หรือไฟล์ annotation จริง ไม่มีการสรุปว่าเป็น YOLO/COCO พร้อมใช้

### 4.2 S. mansoni จำนวน 1,219 คู่ภาพ–mask จาก LIDS-Datasets

- ต้นทางผู้วิจัย: [schistossoma-eggs](https://github.com/LIDS-Datasets/schistossoma-eggs) (ชื่อ repository สะกดตามต้นทาง)
- มี **1,219 ภาพและ 1,219 segmentation masks** จากจำนวนรายการในโฟลเดอร์ `orig` และ `label`; จำนวนใน `orig` มีโฟลเดอร์ checkpoints เพิ่มอีก 1 รายการ จึงไม่นับเป็น 1,220 ภาพ
- README ระบุภาพอุจจาระ S. mansoni และอ้างงาน *Adaptive Decoders for FLIM-based Salient Object Detection Networks*, SIBGRAPI 2024
- แปลง mask เป็นกรอบได้เมื่อทบทวนว่า connected components ตรงกับไข่แต่ละฟองจริง; ภาพไข่ชิดกันหรือขาดส่วนต้องให้ผู้เชี่ยวชาญตรวจ
- ยังไม่พบ license และข้อมูลผู้ป่วย/สไลด์ อุปกรณ์ การเตรียม หรือการอ่านยืนยัน; **ยังไม่ยืนยันการซ้ำกับ LIDS intestinal subset หรือชุด 66 ภาพ** จึงห้ามนำยอดมาบวกเป็นจำนวนผู้ป่วยอิสระ

[AutoFLIM](https://github.com/LIDS-UNICAMP/AutoFLIM) กล่าวถึง benchmark 1,219 ภาพเช่นกัน ให้ถือเป็นหลักฐานประกอบ/แหล่งอาจซ้ำ ไม่ใช่เพิ่มอีก 1,219 ภาพ ชุด few-shot splits ใน repository ไม่ใช่ตัวแทนการแบ่งทดสอบทางคลินิก

### 4.3 หลักฐานเดิมของ Schistosoma อีกสองชนิด

#### OpenUrine — พักไว้จากเป้าหมายปัจจุบัน

[OpenUrine](https://github.com/alikarimi120/OpenUrine) เป็น repository ของผู้เขียนที่มีสังกัด University of Tehran และ Shahid Beheshti University of Medical Sciences ประเทศอิหร่าน README ระบุ **6,430 ภาพตะกอนปัสสาวะ: 790 ภาพมี labels รวม 31,285 bounding boxes ใน 39 กลุ่ม และอีก 5,640 ภาพไม่มี labels** รายการกลุ่มมี S. haematobium และ Enterobius vermicularis แต่ **ยังไม่ทราบจำนวนภาพ/กรอบของพยาธิแต่ละชนิดและระยะที่ annotate** ห้ามเรียก 31,285 boxes ว่าไข่พยาธิทั้งหมด

ผู้เขียนระบุการเก็บจากหลายห้องปฏิบัติการ หลายกล้องจุลทรรศน์/กล้องโทรศัพท์ อ่าน annotation อิสระโดยผู้เชี่ยวชาญชีวเคมีคลินิกสองคน และแบ่งตามผู้ป่วย เหล่านี้เป็นข้อความใน README ที่ยังไม่ได้ตรวจเทียบไฟล์หรือ data dictionary; ยังไม่ทราบวิธีตัดสินความเห็นต่างและจำนวนผู้ป่วยจริง การมี Enterobius ในปัสสาวะไม่ได้ยืนยันผลบนเทปใส

เข้าถึงผ่าน [แบบฟอร์มขอข้อมูล](https://forms.gle/JKgV63B6hdr5XjD29) โดยกำหนด **วิจัยเชิงวิชาการ/ไม่ใช้เชิงพาณิชย์ ห้ามส่งต่อข้อมูลโดยไม่มีอนุญาต และต้องอ้างอิง** ยังไม่มีการยื่นขอแทนผู้ใช้ ต้องยืนยันการนำโมเดลที่ฝึกไป deploy บน HelpMinths ด้วย Repository ที่ตรวจมีเพียง README จึงยังไม่ยืนยันโค้ด/weights/ตัวอย่างภาพที่ข้อความกล่าวถึง งาน Scientific Reports 2025 ที่ผู้เขียนอ้างยังเปิด publisher ตรวจอิสระไม่ได้ ไม่สร้าง DOI ขึ้นเอง

**สถานะปัจจุบัน:** พักไว้นอกลำดับขอข้อมูลสำหรับ 11 กลุ่ม ไม่มี OV และ S. haematobium ออกจากเป้าหมาย การมี Enterobius ในปัสสาวะไม่ยืนยันการตรวจบนเทปใส จึงไม่ใช้เป็นแหล่งหลักของ Enterobius ใน workflow นี้ การพบชื่อใน README ไม่ยืนยันว่ามีไข่เพียงพอสำหรับฝึก

#### Schistoscope — พักไว้จากเป้าหมายปัจจุบัน

Schistoscope เป็นงานจากเครือข่าย Delft/Leiden และผู้ร่วมวิจัยในแอฟริกา มี [งานตีพิมพ์ปี 2022](https://doi.org/10.3390/mi13050643), [author repository](https://github.com/delftopenhardware/Schistoscope) และ [ข้อความบทคัดย่อในเว็บไซต์ผู้เขียน](https://github.com/delftopenhardware/SchistoscopeDocs/blob/main/classic/src/components/HomepageFeatures/index.tsx) ซึ่งกล่าวถึง **มากกว่า 5,000 ภาพจากปัสสาวะทั้งแบบเติมไข่และสิ่งส่งตรวจทางคลินิก** ไม่ใช่ผู้ป่วยติดเชื้อธรรมชาติ 5,000 ราย

อย่างไรก็ตาม [เอกสารข้อมูลของผู้เขียน](https://github.com/delftopenhardware/SchistoscopeDocs/blob/main/classic/docs/docs_data/intro.md) ระบุชัดว่า “Currently the dataset used to train the algorithm is not available…” จึงเป็น **แหล่งติดตาม/ขอความร่วมมือ ยังไม่ยืนยันว่าเป็น dataset เปิดที่ดาวน์โหลดฝึกได้** หน้านี้อาจเก่ากว่า release ใหม่ ต้องตรวจสถานะล่าสุดกับเจ้าของ ยังไม่มีการติดต่อแทนผู้ใช้

ลิงก์ Zenodo `10211154` ในเอกสารซอฟต์แวร์เป็น image ระบบปฏิบัติการสำหรับ Raspberry Pi ไม่ใช่ชุดภาพไข่พยาธิ ต้องแยกออกจากทะเบียนภาพฝึก

#### S. japonicum — ไม่ติดตามเป็นเป้าหมายในระยะนี้

การค้นครั้งนี้ยังไม่ยืนยันชุดภาพไข่ S. japonicum ที่มี annotation สำหรับ detection พร้อมต้นทางและสิทธิ์ที่ตรวจได้ ไม่ได้แปลว่าไม่มีข้อมูลอยู่ที่ใดในโลก พักการค้นต่อในขอบเขตปัจจุบัน; หากขยายงานภายหลังจึงติดตามผู้เขียน/สถาบันที่มีสิ่งส่งตรวจจริง ข้อมูลจีโนม ภาพอัลตราซาวนด์ตับ และภาพอวัยวะไม่ใช้แทนข้อมูลไข่กล้องจุลทรรศน์

- ข้อมูลไข่พยาธิสัตว์หรือโปรโตซัว/Babesia/Toxoplasma ไม่แทน 11 กลุ่มเป้าหมายในแอพ อาจเป็นข้อมูลเสริมที่ระบุบทบาทชัดเจนเมื่อมีเหตุผลและสิทธิ์รองรับ

## 6. จาก dataset ไปสู่ความแม่นยำที่ตรวจสอบได้

1. **เคลียร์ต้นทางและสิทธิ์ก่อนนำเข้า:** บันทึกรุ่น, checksum, สิทธิ์ภาพ/annotation/weights, patient–specimen–slide IDs, วิธีเตรียมและอุปกรณ์ ตรวจกรอบตกหล่น ไฟล์เสีย class mapping รวม OV raw label และนิยามกลุ่ม MIF/Echinostoma ตลอดจน duplicates ข้ามทุกแหล่ง เก็บ label นอกขอบเขตไว้ชัดเจน; การคัดคลาสเป้าหมายต้องไม่ทำให้ไข่อื่นกลายเป็น negative ที่ติดป้ายผิด
2. **เพิ่มภาพเต็มจากงานจริง:** เก็บภาพจากกล้องจุลทรรศน์และโทรศัพท์เป้าหมาย มีทั้งหลายฟอง การติดเชื้อร่วม ภาพไม่พบไข่ และฟองอากาศ เศษพืช เซลล์/วัสดุในเทป รวมถึงไข่ชนิดนอกขอบเขตและไข่คล้าย OV/MIF และ Echinostoma/Fasciolopsis/Fasciola ให้ผู้เชี่ยวชาญอย่างน้อยสองคนอ่าน subset ที่กำหนดอย่างอิสระและมีผู้ตัดสินความเห็นต่าง
3. **แบ่งกลุ่มก่อน crop/augment:** แยก train/validation/test ตามผู้ป่วยหรือสไลด์ รวมภาพหลาย field/focus ของตัวอย่างเดียวไว้ฝั่งเดียวกัน แยกชุดทดสอบภายนอกจากห้องปฏิบัติการ ช่วงเวลา หรืออุปกรณ์ใหม่ และไม่ใช้ชุดนี้ปรับ threshold หรือสร้าง pseudo-label ฝึกต่อ
4. **ฝึก baseline detector:** เช่น YOLO/Faster R-CNN ที่รับภาพเต็ม/patch เมื่อไข่เล็ก และตรวจการรวมกรอบซ้ำ; แยกวิเคราะห์ stool และ tape เพราะพื้นหลังและ SOP ต่างกัน; ภาพปัสสาวะอยู่นอก workflow เป้าหมายปัจจุบัน ไม่ให้โมเดลเดาจากชนิดพื้นหลังเพียงอย่างเดียว
5. **ประเมินรายชนิดพร้อมช่วงความเชื่อมั่น:** precision, recall, mAP@0.5/mAP@0.5:0.95 และ false positives ต่อภาพ/สไลด์; แยกตามอุปกรณ์ วิธีเตรียม ภาพคุณภาพต่ำ low-intensity และกลุ่มไข่คล้ายกัน ได้แก่ OV/MIF, H. nana/H. diminuta และ Echinostoma/Fasciolopsis/Fasciola หากประเมินระดับผู้ป่วยต้องมี reference standard และรายงาน sensitivity/specificity/PPV/NPV แยกจาก mAP กำหนดขนาดชุดทดสอบร่วมกับอาจารย์/นักสถิติจากความกว้างช่วงความเชื่อมั่นที่ต้องการ
6. **นำเข้าแอพเมื่อผ่านการทดสอบ:** เปิดใช้เฉพาะคลาสที่มีข้อมูลและหลักฐานผลจริง มีผลไม่แน่ใจ/ภาพคุณภาพต่ำและมนุษย์ตรวจยืนยัน ไม่พบไข่ในหนึ่งรูปไม่ได้ยืนยันว่าไม่มีการติดเชื้อ ค่า confidence ไม่ใช่ความน่าจะเป็นที่ผู้ป่วยเป็นโรค
7. **ทดสอบออฟไลน์ภายหลัง:** export โมเดลที่ผ่าน validation เป็นรูปแบบเหมาะกับอุปกรณ์ เช่น ONNX แล้วทดสอบ output หลัง export/quantization, RAM และเวลาบนโทรศัพท์จริง การ cache หน้าเว็บ/Atlas ไม่ทำให้ API ตรวจภาพประมวลผลออฟไลน์โดยอัตโนมัติ

**ผลที่คาดหวังได้ในระยะถัดไป:** registry ที่สิทธิ์ครบ, ชุดภาพเต็มพร้อมกรอบที่ผู้เชี่ยวชาญยืนยัน, baseline detector และผลทดสอบรายคลาสบนข้อมูลที่ไม่รั่วไหล จึงค่อยพิจารณาการอ้างประโยชน์ทางคลินิก ยังระบุความแม่นยำไม่ได้ก่อนทดสอบภายนอก และยังไม่ยืนยันการตรวจครบ 11 กลุ่ม ณ ตอนนี้

## 7. ขอบเขตการตรวจสอบและไฟล์ประกอบ

ตรวจหน้า README/configuration/manifests จาก GitHub ของผู้วิจัย/สถาบันได้โดยตรง รวมทั้งขนาดตัวอย่าง LIDS บางภาพ รอบปรับขอบเขตนี้ตรวจ configuration Chula ที่บันทึกไว้ซ้ำและพบชื่อ `Opisthorchis viverrine`, `Hymenolepis nana`, `Hymenolepis diminuta` และ `Fasciolopsis buski` แต่ไม่พบ MIF/Echinostoma ไม่ได้ตรวจ original annotation หรือดาวน์โหลด microscopy corpus ทั้งหมดหรือฝึกโมเดล หลายเว็บไซต์ต้นทางรวม DataPort, Kaggle, Mendeley, CDC และ publisher ถูก proxy ตอบ CONNECT 403 ก่อน TLS จึงแยก “หลักฐานที่อ่านได้” ออกจาก “ต้นทางที่ยังต้องเปิดตรวจ” อย่างชัดเจน การติดข้อจำกัดเครือข่ายนี้ไม่ใช่หลักฐานว่าลิงก์สาธารณะเสีย

- [dataset_catalog.csv](dataset_catalog.csv): ทะเบียนต้นทาง/หลักฐาน คลาส จำนวนและหน่วย annotation สิทธิ์ สถานะดาวน์โหลด บทบาท และช่องว่าง metadata สำหรับติดตามต่อ
- แหล่งอ้างอิงต้นทางและหลักฐานที่อ่านได้เชื่อมไว้ในแต่ละหัวข้อข้างต้น; ไม่ถือว่าหน้าเว็บที่เข้าถึงไม่ได้ได้รับการตรวจสดแล้ว

ไม่มีการติดต่อบุคคลภายนอก ขออนุญาตแทนผู้ใช้ ดาวน์โหลดข้อมูลจำนวนมาก หรือเปลี่ยนสถานะ trained model จากการปรับเอกสารครั้งนี้
