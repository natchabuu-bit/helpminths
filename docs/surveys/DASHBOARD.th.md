# Dashboard ที่ปรับจาก helminth-dashboard.zip

หน้าเมนู Dashboard (`/#dashboard`) ใช้การจัดวางและโทนสีจากไฟล์ `helminth-dashboard.zip` ที่เจ้าของส่งให้เมื่อ 31 ตุลาคม 2569 ได้แก่หัวสรุปสีเขียวเข้ม ตัวเลขสีทอง วงแหวนความครอบคลุม ตัวกรอง กราฟกระจาย รายการพื้นที่ติดตาม กราฟแท่ง และตารางเรียงลำดับ หน้าทั้งหมดอยู่ภายใน HelpMinths และใช้ตัวอักษรที่รวมกับแอป ไม่โหลด Google Fonts หรือ JavaScript ภายนอก

SHA-256 ของไฟล์ ZIP ที่ใช้เป็นต้นแบบคือ `93281b5f1ea6629a4457ff4f25b5a3c65cb77a17b3b139e574317d84150e8c2a` ไม่เผยแพร่ข้อมูลรายสถานศึกษาที่แนบอยู่ใน ZIP โดยใช้ชุดข้อมูลสรุปที่ตรวจสอบจาก Excel ไว้แล้วเป็นแหล่งเดียว

## อ่านหน้า Dashboard

- ตัวเลขสีทองแสดงร้อยละตรวจพบในกลุ่มผู้ส่งตรวจ 1 ตำแหน่งตามรูปแบบต้นแบบ (4.4%) ตารางและผลวิเคราะห์เก็บความละเอียด 2 ตำแหน่ง (4.39%) เป็นการปัดเลขเดียวกัน
- วงแหวนแสดงความครอบคลุมเฉพาะนักเรียนที่มีจำนวนรายงาน ไม่รวมจำนวนที่ยังไม่ทราบในหน่วยรอข้อมูล
- กราฟกระจายใช้ **1 จุดต่ออำเภอ** แกนจำนวนส่งตรวจเป็นสเกลลอการิทึม ขนาดจุดตามจำนวนผู้ตรวจพบ เลือกจุดด้วยเมาส์/สัมผัส หรือ Tab และ Enter/Space เพื่อกรองพื้นที่
- รายการพื้นที่ติดตามเรียงร้อยละรายอำเภอ โดยแสดงเฉพาะอำเภอที่มีผู้ส่งตรวจตั้งแต่ 30 คนและมีผู้ตรวจพบ เกณฑ์นี้ใช้จัดแสดงข้อมูล ไม่ใช่เกณฑ์ความเสี่ยงทางคลินิก
- กราฟอำเภอและสังกัดเลือกเพื่อกรองได้ โดยแสดงจำนวนผู้ตรวจพบและจำนวนผู้ส่งตรวจประกอบร้อยละเสมอ
- ชนิดพยาธิใช้ความยาวแท่งตามจำนวนรายงาน แสดงจำนวนขัดกัน/ช่องจำนวนว่างแยกไว้ ไม่รวมรายชนิดเป็นจำนวนคนทั้งหมด หมวดใบไม้ลำไส้ขนาดกลางไม่ถูกเปลี่ยนเป็น MIF
- เลือกปุ่มช่วงร้อยละเพื่อกรองทั้งยอด กราฟ ข้อสังเกต และตาราง จำนวนบนปุ่มแสดงทุกช่วงภายใต้ตัวกรองพื้นที่/สังกัด/สถานะเดียวกัน เพื่อเปลี่ยนไปช่วงอื่นได้
- ตารางสลับอำเภอ จังหวัด และสังกัดได้ เลือกหัวคอลัมน์เพื่อเรียงลำดับ ค้นหาชื่อพื้นที่/สังกัดได้ คำค้นมีผลเฉพาะตารางและ CSV ที่ดาวน์โหลดจากตารางนั้น
- เปิด “หมายเหตุข้อมูลและแหล่งที่มา” เพื่อดูชื่อไฟล์ แท็บ เวอร์ชัน เวลานำเข้า วิธีคำนวณ และเซลล์ที่ควรตรวจทาน

## ช่วงร้อยละและการนับหน่วย

ช่วงเป็นการบรรยายข้อมูลของหน่วยรายงาน ไม่ใช่ระดับความเสี่ยงหรือคำแนะนำรักษา คำนวณจากค่าจริงก่อนปัดทศนิยม:

| ช่วง | จำนวนหน่วย |
| --- | ---: |
| ไม่พบ: 0% | 61 |
| มากกว่า 0% แต่น้อยกว่า 5% | 51 |
| ตั้งแต่ 5% แต่น้อยกว่า 10% | 32 |
| ตั้งแต่ 10% แต่น้อยกว่า 20% | 15 |
| ตั้งแต่ 20% | 11 |
| **รวมหน่วยที่มีผู้ส่งตรวจ** | **170** |

อีก 2 หน่วยรายงานส่งตรวจศูนย์ และ 2 หน่วยรอข้อมูลอยู่ในยอดรวม 174 หน่วย ไม่จัดเข้าช่วง “ตรวจแล้วไม่พบ” การเลือกช่วงจึงจำกัดข้อมูลเหลือเฉพาะหน่วยที่มีผู้ส่งตรวจแล้ว

ข้อมูลเข็มหมุดตามต้นฉบับยังเป็น 7 คน โดยมี 1 คนที่ตัวเลขขัดกับยอดส่งตรวจศูนย์ เมื่อกรองเฉพาะหน่วยที่มีผู้ส่งตรวจจริงจึงเหลือ 6 คน การเปลี่ยนตามตัวกรองไม่ได้แก้หรือลบค่าต้นฉบับ ช่องไส้เดือน/ตืดที่ว่างไม่ถูกเติมเป็นศูนย์ และหน่วยรอข้อมูลทั้งหมดแสดงจำนวนคนเป็น “—”

การเผยแพร่จำกัดเฉพาะสถิติสรุปตามที่เจ้าของกำหนด จึงปรับกราฟ/อันดับ/ตารางรายโรงเรียนในต้นแบบเป็นระดับพื้นที่และสังกัด ไม่มีชื่อสถานศึกษา ตำบล หรือข้อมูลรายบุคคลในไฟล์เว็บหรือ API
