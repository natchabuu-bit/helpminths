# ลดเวลารอตรวจโดยคงภาพและโมเดลเดิม

การปรับครั้งนี้ลดงานซ้ำก่อนรันโมเดล ไม่เปลี่ยน checkpoint, ความละเอียดที่โมเดลใช้, confidence, NMS, precision, อุปกรณ์ CPU หรือจำนวนเธรดของโมเดล การถอดรหัสภาพ การหมุนตาม EXIF และการเก็บ PNG ยังคงเดิม

## สิ่งที่ปรับ

1. เมื่อกดวิเคราะห์โดยยังไม่ได้ตรวจคุณภาพ จะส่งไฟล์ภาพเข้า endpoint วิเคราะห์ครั้งเดียว เซิร์ฟเวอร์ตรวจคุณภาพก่อนอนุญาตให้โมเดลทำงานตามเดิม แทนการอัปโหลดภาพเพื่อตรวจคุณภาพแล้วอัปโหลดภาพเดิมซ้ำอีกครั้ง
2. ภาพที่มีข้อจำกัดยังถูกหยุดก่อนรันโมเดล ผู้ใช้ต้องรับทราบและระบุเหตุผลตามกฎเดิม ปุ่มตรวจคุณภาพภาพด้วยตนเองยังใช้งานได้
3. คำนวณค่าความคมชัดด้วย NumPy เมื่อมีติดตั้ง โดยใช้พิกเซลเดิม สูตรเดิม และผลรวมจำนวนเต็มที่ไม่ล้นช่วง ค่าคุณภาพและเกณฑ์ตัดสินต้องตรงกับวิธีเดิมทุกค่า หากไม่มี NumPy จะใช้วิธีเดิมอัตโนมัติ ไม่มี dependency ใหม่สำหรับการติดตั้ง API แบบพื้นฐาน

ไม่ลดขนาดภาพ ไม่เพิ่มเกณฑ์เพื่อตัดกรอบออก ไม่เปลี่ยนชนิดโมเดล และไม่แปลงเป็นโมเดลความละเอียดตัวเลขต่ำลง

## หลักฐานเปรียบเทียบ

ทดสอบโมเดลสำเนาที่ผู้ใช้เคยอัปโหลดไว้ SHA-256 `5615bcfcd4f0e283a48a59ec74b2457506b6cc98dc059fda0e9477c8580ad11a` กับภาพ Atlas ที่มีสิทธิ์ใช้ 11 ภาพ ภาพละ 3 รอบแบบก่อน/หลัง รวม 66 ครั้ง พบว่าผลตรวจคุณภาพ พิกเซล RGB, PNG ที่บันทึก และรายการตรวจจับทั้งหมดตรงกัน รวมถึงกรอบ ชนิด ลำดับ และค่าความมั่นใจ

ค่ามัธยฐานในเครื่องทดสอบ CPU เดียวกัน หลังผ่านการเริ่มโมเดลครั้งแรก:

| ขั้นตอน | ก่อนปรับ | หลังปรับ |
| --- | ---: | ---: |
| ตรวจคุณภาพภาพ | 43.91 ms | 3.35 ms |
| ถอดรหัส + ตรวจคุณภาพ + เก็บ PNG + รันโมเดล | 174.38 ms | 122.26 ms |
| รันโมเดลอย่างเดียว | 38.91 ms | 38.03 ms |

เวลารันโมเดลเองใกล้เคียงเดิม ความต่างเล็กน้อยเป็นความแปรผันของการวัด การลดเวลาเกิดจากงานเตรียมภาพ และการส่งไฟล์ซ้ำที่ตัดออกจากเว็บ ตัวเลขในตารางไม่รวมอัปโหลด เครือข่าย ฐานข้อมูล หรือเวลาเริ่มโฮสต์

สำเนาโมเดลที่ใช้ทดสอบนี้อาจต่างจากโมเดลรุ่นใหม่ที่โฮสต์ดึงจาก Drive จึงไม่ใช้ตัวเลขนี้รับรองความเร็วหรือความแม่นยำของโมเดลที่กำลังใช้งานบน Render ภาพเพื่อการศึกษาไม่ใช่ชุดประเมินความแม่นยำทางคลินิกแบบอิสระ การทดสอบนี้ตรวจว่าการปรับโปรแกรมคงผลเดิมไว้

## ตรวจสอบและเผยแพร่

```bash
python -m pytest backend/tests/test_quality_equivalence.py backend/tests/test_platform_analysis.py -q
npm run build
```

ชุดทดสอบเบราว์เซอร์ `npm run test:scan-efficiency` ต้องใช้ fixture ชั่วคราวบน localhost ที่เปิดอย่างชัดเจนเท่านั้น ตรวจจำนวนคำขอจริง พิกเซลที่บันทึก และขั้นตอนยืนยันภาพที่มีข้อจำกัด ไม่ใช้ทดสอบเขียนข้อมูลบนเว็บจริง

เผยแพร่ด้วย Render → Manual Deploy → Deploy latest commit การเริ่มโฮสต์หลังพักบน Render Free และการเริ่มโมเดลครั้งแรกยังใช้เวลาได้ ความเร็วรวมต้องวัดจากอุปกรณ์และภาพที่ใช้จริง ไม่มีการเปลี่ยนแพ็กเกจโฮสต์หรือเพิ่มค่าใช้จ่ายอัตโนมัติ
