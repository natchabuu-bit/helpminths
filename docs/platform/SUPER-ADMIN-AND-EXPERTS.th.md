# Super Admin การอนุมัติบัญชี และงานตรวจยืนยัน

ชื่อบัญชีที่เตรียมไว้คือ **Super Admin** ไม่มีรหัสผ่านเริ่มต้นหรือรหัสผ่านสำเร็จรูปในโค้ด เจ้าของกำหนดรหัสผ่านจริงผ่าน Environment ของ Render หนึ่งค่า ระบบสร้างหรือกู้บัญชีเจ้าของให้เมื่อเริ่มแอป

## เปิดหลังบ้านให้เข้าได้จริง

1. เปิด **Render → helpminths → Environment → Add Environment Variable**
2. ใส่ชื่อ `HELPMINTHS_SUPER_ADMIN_PASSWORD` และใส่รหัสผ่านที่คุณต้องการใช้จริงอย่างน้อย 4 ตัวอักษรเป็นค่า เก็บเป็นความลับบน Render ไม่ใส่ใน Git และไม่ต้องส่งรหัสผ่านมาทางแชท
3. บันทึก แล้วกด **Manual Deploy → Deploy latest commit** ให้รุ่นใหม่นี้ทำงาน
4. เปิด [หลังบ้าน Super Admin](https://helpminths.onrender.com/admin/) กรอกชื่อ **Super Admin** และรหัสผ่านที่คุณตั้งใน Render กด **เข้าสู่หลังบ้าน** ได้ในหน้านี้โดยตรง
5. เมื่อเข้าสำเร็จ ส่วน **อนุมัติคำขอและจัดการสมาชิก** พร้อมปุ่ม **รออนุมัติ** จะอยู่ถัดจากข้อมูลบัญชีผู้ดูแล เลือกคำขอแล้วอนุมัติหรือไม่อนุมัติได้

ถ้า Render ตั้ง `HELPMINTHS_OWNER_USERNAME` ไว้เป็นชื่ออื่น ระบบใช้ชื่อนั้นเป็นชื่อเป้าหมาย หน้าล็อกอินแสดงชื่อบัญชีเจ้าของที่มีอยู่จริง หากเคยมีบัญชีเจ้าของและลืมรหัส การตั้ง/เปลี่ยน `HELPMINTHS_SUPER_ADMIN_PASSWORD` บนโฮสต์จะกู้บัญชีเจ้าของเดิม ไม่สร้างเจ้าของคนที่สองและไม่ย้ายผลตรวจไปอีกบัญชี การชนชื่อกับบัญชีอื่นจะหยุดการกู้โดยไม่ยกระดับบัญชีนั้น

รหัสผ่านจากโฮสต์ถูกใช้เฉพาะครั้งแรกหรือเมื่อเปลี่ยนค่านั้น หลังจากคุณเปลี่ยนชื่อ/รหัสผ่านผ่านหน้าบัญชี การเริ่มแอปใหม่ด้วยค่า Environment เดิมและฐานข้อมูลเดิมจะไม่ย้อนรหัสผ่านกลับ เก็บหลักฐานค่าที่เคยใช้เป็น hash แบบใส่ salt ในฐานข้อมูลส่วนตัว ไม่เปิดผ่าน API หรือ audit ผู้ดูแล

หลังบ้านเป็นหน้าเว็บแยกที่ **`/admin/`** ใช้โทนเข้มและไม่มีเมนูตรวจภาพของเว็บหลัก เจ้าของเปิด URL นี้ได้โดยตรง หรือใช้ปุ่ม **เปิดหลังบ้าน** ในหน้าบัญชี ลิงก์ `/#admin` เดิมเปลี่ยนไปหน้าใหม่อัตโนมัติ ชื่อบัญชีเพียงอย่างเดียวไม่ได้ให้สิทธิ์ Super Admin บัญชีทั่วไปหรือผู้ดูแลที่ไม่ใช่เจ้าของยังเข้าไม่ได้ ทั้งสองหน้าใช้โฮสต์เดียวกันและตรวจสิทธิ์จากเซิร์ฟเวอร์ทุกครั้ง หากต้องการคนละโดเมนต้องตั้งค่าโฮสต์เพิ่มต่างหาก

## ทางเลือกเดิมสำหรับเจ้าของโฮสต์

เส้นทาง `HELPMINTHS_ADMIN_SETUP_TOKEN` และ CLI ยังรองรับเพื่อความเข้ากันได้ แต่ไม่จำเป็นเมื่อใช้รหัสผ่านโฮสต์ด้านบนแล้ว สำหรับ CLI ให้ใช้ฐานข้อมูลเดียวกับเว็บ:

```bash
python -m backend.platform.bootstrap --username 'Super Admin'
```

CLI ถามรหัสผ่านผ่าน terminal ไม่ใส่รหัสผ่านใน command line การตั้งเจ้าของครั้งแรกผ่านเว็บแบบโทเคนปิดเมื่อมีเจ้าของแล้ว

## อนุมัติสมาชิก

สมาชิกเลือกสมัคร **ผู้ใช้ทั่วไป** หรือ **ผู้เชี่ยวชาญ** ตั้งชื่อบัญชีและรหัสผ่าน พร้อมกรอก **ชื่อ-นามสกุล สถานที่ทำงาน สังกัด และเบอร์โทร 10 หลัก** ให้ครบทั้งสองประเภทบัญชี การสมัครจะสร้างคำขอรออนุมัติและไม่เปิด session สำหรับตรวจภาพ บัญชีเดิมยังเข้าสู่ระบบได้ตามปกติและแก้ข้อมูลส่วนตัวได้ในหน้าตั้งค่าโดยยืนยันรหัสผ่านปัจจุบัน

เจ้าของเข้าสู่ระบบ เปิด **หลังบ้าน → รออนุมัติ** เลือกคำขอ เปิดรายละเอียดชื่อ สถานที่ทำงาน สังกัด และเบอร์โทร ตรวจสอบตัวบุคคลและคุณสมบัตินอกระบบ แล้วอนุมัติหรือปฏิเสธ เลือกสิทธิ์ให้ตรงกับหน้าที่ได้ ส่วนอนุมัติสมาชิกแสดงเฉพาะในหลังบ้าน การอนุมัติผู้เชี่ยวชาญไม่ใช่การรับรองวิชาชีพอัตโนมัติ

เฉพาะเจ้าของระบบเท่านั้นที่อนุมัติบัญชีหรือจัดการสิทธิ์ การเปลี่ยนสิทธิ์ ปฏิเสธ หรือพักบัญชียกเลิก session เดิม การแก้บัญชีของเจ้าของไม่สามารถถอนสิทธิ์หรือปิดบัญชีเจ้าของเองจากเมนูนี้

## ผู้เชี่ยวชาญตอบกลับและขอภาพเพิ่มเติม

1. ผู้เชี่ยวชาญที่อนุมัติแล้วใช้หน้าสมัคร/เข้าสู่ระบบผู้เชี่ยวชาญ การเข้าสู่ระบบนี้ยืนยันรหัสผ่านและเปิดสิทธิ์ตรวจครั้งละ 15 นาที
2. เปิด **ทบทวนโดยผู้เชี่ยวชาญ → รอตรวจ** เลือกภาพ อ่านผล AI และคำถามจากผู้ส่ง
3. พิมพ์คำตอบเพื่อ **ส่งคำตอบ** ระหว่างตรวจ หรือกด **ขอภาพเพิ่มเติมจากผู้ส่ง** พร้อมคำอธิบาย ภาพจะยังอยู่ฝั่งรอตรวจ
4. ผู้ส่งเปิดรายการเดิม อ่านคำขอและแนบภาพเพิ่มเติมได้ ภาพเพิ่มเติมเป็นหลักฐานประกอบ ไม่แทนภาพต้นฉบับหรือผล AI เดิม เมื่อแนบสำเร็จรายการกลับเข้าคิวรอตรวจ
5. ก่อนยืนยันผล ผู้เชี่ยวชาญต้องตรวจภาพทั้งภาพและจัดการกรอบที่ AI รายงานให้ครบตามแบบตรวจเดิม จากนั้นยืนยันผลและส่งคำตอบ รายการจะไป **เสร็จสิ้น**

ข้อความ วันที่ ผู้ส่ง ผู้ตอบ และภาพแนบแสดงในรายการเดียวกัน ภาพอ่านได้ตามสิทธิ์บัญชี ไม่เผยแพร่เป็นไฟล์สาธารณะ

เมื่อผู้เชี่ยวชาญส่งคำตอบ ขอภาพเพิ่ม หรือบันทึกผลตรวจทาน ผู้ส่งได้รับการแจ้งเตือนที่กระดิ่งมุมขวาบน **แต่ละคำตอบเป็นรายการแยกกัน** แสดงรหัสภาพและเวลา กดแล้วเปิดภาพ คำตอบ และรอบส่งต่อนั้นโดยตรง แม้ภาพเดียวกันเคยส่งต่อหลายรอบ คำตอบผู้เชี่ยวชาญแสดงในกรอบเด่น การเปิดแจ้งเตือนเปลี่ยนสถานะเป็นอ่านแล้วเฉพาะรายการนั้น รายการอื่นยังคงรออ่าน

แอปตรวจการแจ้งเตือนใหม่ทุก 30 วินาทีขณะเปิดหน้าออนไลน์ และเมื่อกลับมายังหน้าเว็บ การแจ้งเตือนอยู่ในบัญชีผู้ส่งเท่านั้น ไม่มีการส่งอีเมลหรือเปิดเป็นข้อมูลสาธารณะ ข้อมูลนี้ใช้ฐานข้อมูลและข้อจำกัดพื้นที่จัดเก็บเดียวกับผลตรวจ

ปุ่มบัญชีด้านขวาบนเปิดเมนูชื่อ-นามสกุล สถานะผู้ใช้งาน **ตั้งค่า** และ **ออกจากระบบ** ข้อมูลส่วนตัวใช้ในบัญชีและการอนุมัติ ไม่แสดงใน Dashboard สาธารณะ

## ประวัติทุกวันของแต่ละบัญชี

**ประวัติการตรวจรายวัน** แสดงข้อมูลของบัญชีที่เข้าสู่ระบบเท่านั้น เลือกดูทั้งหมด รอผู้เชี่ยวชาญ หรือรายการที่ไม่ค้างในคิว เลือกวันหรือช่วงวันย้อนหลังและค้นหารหัสตัวอย่างได้ เวลาที่แสดงใช้ประเทศไทย

ประวัติเก็บรหัสรายการ ภาพ ผล AI เดิม และการส่งต่อ รายการส่งต่อไม่สร้างภาพต้นฉบับซ้ำ และเมื่อเสร็จยังคงวันที่ตรวจเดิม การตอบและภาพแนบเพิ่มเติมมีวันเวลาของเหตุการณ์แยกต่างหาก

## พื้นที่เก็บประวัติ

การอัปเดตนี้ไม่เปลี่ยนแพ็กเกจโฮสต์หรือสร้าง Persistent Disk บัญชีและประวัติบน filesystem ชั่วคราวของ Render Free อาจหายเมื่อโฮสต์เริ่มใหม่หรือ deploy การเก็บย้อนหลังระยะยาวต้องใช้พื้นที่ถาวรและสำรองข้อมูลแยกต่างหาก ดู [คู่มือบัญชีและพื้นที่จัดเก็บ](ACCOUNTS-AND-REFERRALS.th.md)
