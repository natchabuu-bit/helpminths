# Super Admin การอนุมัติบัญชี และงานตรวจยืนยัน

ชื่อบัญชีเจ้าของระบบที่เตรียมไว้คือ **Super Admin** รหัสผ่านให้เจ้าของตั้งเองในหน้าเว็บ ไม่มีบัญชีหรือรหัสผ่านเริ่มต้นฝังในโค้ด

## เปิดสิทธิ์เจ้าของระบบครั้งแรก

ถ้ามีผู้ดูแลจากรุ่นเดิมอยู่แล้ว ระบบจะรักษาบัญชีผู้ดูแลที่ใช้งานอยู่และสร้างก่อนคนอื่นให้เป็นเจ้าของระบบ ไม่เปลี่ยนชื่อหรือรหัสผ่านเดิม ต้องเข้าสู่ระบบใหม่หลังอัปเดต ส่วนบัญชีอื่นจากรุ่นเดิมจะรอให้เจ้าของอนุมัติ ประวัติ ภาพ และผล AI เดิมยังอยู่บนพื้นที่จัดเก็บเดิม

หากยังไม่มีเจ้าของระบบ:

1. ใน Render เปิดบริการ **helpminths → Environment** เพิ่ม `HELPMINTHS_ADMIN_SETUP_TOKEN` เป็นค่าสุ่มส่วนตัว 32–256 ตัวอักษร ASCII ที่ไม่มีช่องว่าง เก็บค่าไว้กับเจ้าของโฮสต์ ไม่ใส่ใน Git หรือส่งให้สมาชิก
2. Deploy รุ่นล่าสุด แล้วเปิดเว็บ **ตั้งค่าและบัญชี → ตั้งค่า Super admin ครั้งแรก**
3. ใช้ชื่อ **Super Admin** กรอกรหัสตั้งค่าจากข้อ 1 และตั้งรหัสผ่านบัญชีของคุณเอง พร้อมยืนยัน ระบบจะเปิดสิทธิ์เจ้าของได้ครั้งเดียว
4. หลังสำเร็จ การตั้งเจ้าของใหม่ผ่านหน้าเว็บจะปิดอัตโนมัติ เก็บรหัสตั้งค่าไว้เป็นความลับของเจ้าของโฮสต์ ไม่ต้อง deploy ซ้ำเพื่อลบค่าระหว่างทดสอบบนพื้นที่ชั่วคราว

ตัวแปร `HELPMINTHS_OWNER_USERNAME` ใช้เปลี่ยนชื่อที่เตรียมไว้ ค่าเริ่มต้นคือ `Super Admin` ชื่อบัญชีรองรับช่องว่างภายใน ส่วน CLI สำหรับผู้ดูแลโฮสต์ยังใช้งานได้:

```bash
python -m backend.platform.bootstrap --username 'Super Admin'
```

CLI ถามรหัสผ่านผ่าน terminal และต้องใช้ฐานข้อมูลเดียวกับเว็บ ไม่ใส่รหัสผ่านใน command line

## อนุมัติสมาชิก

สมาชิกเลือกสมัคร **ผู้ใช้ทั่วไป** หรือ **ผู้เชี่ยวชาญ** แล้วตั้งชื่อบัญชีและรหัสผ่าน การสมัครจะสร้างคำขอรออนุมัติและไม่เปิด session สำหรับตรวจภาพ

เจ้าของเข้าสู่ระบบ เปิด **ตั้งค่าและบัญชี → Super admin** เลือกคำขอรออนุมัติ ตรวจสอบตัวบุคคลและคุณสมบัตินอกระบบ แล้วอนุมัติหรือปฏิเสธ เลือกสิทธิ์ให้ตรงกับหน้าที่ได้ การอนุมัติผู้เชี่ยวชาญไม่ใช่การรับรองวิชาชีพอัตโนมัติ

เฉพาะเจ้าของระบบเท่านั้นที่อนุมัติบัญชีหรือจัดการสิทธิ์ การเปลี่ยนสิทธิ์ ปฏิเสธ หรือพักบัญชียกเลิก session เดิม การแก้บัญชีของเจ้าของไม่สามารถถอนสิทธิ์หรือปิดบัญชีเจ้าของเองจากเมนูนี้

## ผู้เชี่ยวชาญตอบกลับและขอภาพเพิ่มเติม

1. ผู้เชี่ยวชาญที่อนุมัติแล้วใช้หน้าสมัคร/เข้าสู่ระบบผู้เชี่ยวชาญ การเข้าสู่ระบบนี้ยืนยันรหัสผ่านและเปิดสิทธิ์ตรวจครั้งละ 15 นาที
2. เปิด **ทบทวนโดยผู้เชี่ยวชาญ → รอตรวจ** เลือกภาพ อ่านผล AI และคำถามจากผู้ส่ง
3. พิมพ์คำตอบเพื่อ **ส่งคำตอบ** ระหว่างตรวจ หรือกด **ขอภาพเพิ่มเติมจากผู้ส่ง** พร้อมคำอธิบาย ภาพจะยังอยู่ฝั่งรอตรวจ
4. ผู้ส่งเปิดรายการเดิม อ่านคำขอและแนบภาพเพิ่มเติมได้ ภาพเพิ่มเติมเป็นหลักฐานประกอบ ไม่แทนภาพต้นฉบับหรือผล AI เดิม เมื่อแนบสำเร็จรายการกลับเข้าคิวรอตรวจ
5. ก่อนยืนยันผล ผู้เชี่ยวชาญต้องตรวจภาพทั้งภาพและจัดการกรอบที่ AI รายงานให้ครบตามแบบตรวจเดิม จากนั้นยืนยันผลและส่งคำตอบ รายการจะไป **เสร็จสิ้น**

ข้อความ วันที่ ผู้ส่ง ผู้ตอบ และภาพแนบแสดงในรายการเดียวกัน ภาพอ่านได้ตามสิทธิ์บัญชี ไม่เผยแพร่เป็นไฟล์สาธารณะ

## ประวัติทุกวันของแต่ละบัญชี

**ประวัติการตรวจรายวัน** แสดงข้อมูลของบัญชีที่เข้าสู่ระบบเท่านั้น เลือกดูทั้งหมด รอผู้เชี่ยวชาญ หรือรายการที่ไม่ค้างในคิว เลือกวันหรือช่วงวันย้อนหลังและค้นหารหัสตัวอย่างได้ เวลาที่แสดงใช้ประเทศไทย

ประวัติเก็บรหัสรายการ ภาพ ผล AI เดิม และการส่งต่อ รายการส่งต่อไม่สร้างภาพต้นฉบับซ้ำ และเมื่อเสร็จยังคงวันที่ตรวจเดิม การตอบและภาพแนบเพิ่มเติมมีวันเวลาของเหตุการณ์แยกต่างหาก

## พื้นที่เก็บประวัติ

การอัปเดตนี้ไม่เปลี่ยนแพ็กเกจโฮสต์หรือสร้าง Persistent Disk บัญชีและประวัติบน filesystem ชั่วคราวของ Render Free อาจหายเมื่อโฮสต์เริ่มใหม่หรือ deploy การเก็บย้อนหลังระยะยาวต้องใช้พื้นที่ถาวรและสำรองข้อมูลแยกต่างหาก ดู [คู่มือบัญชีและพื้นที่จัดเก็บ](ACCOUNTS-AND-REFERRALS.th.md)
