# ผล AI ผลผู้เชี่ยวชาญ และคลังภาพหลังบ้าน

## อ่านผลตรวจอย่างชัดเจน

หน้าเปิดผลตรวจแยกเป็นสองช่อง:

- **AI ทำนาย** แสดงชนิดและจำนวนตำแหน่งที่โมเดลรายงานไว้เดิม
- **ผู้เชี่ยวชาญ** แสดงชนิดและจำนวนที่ยืนยันแล้ว พร้อมคำอธิบาย ผู้ตรวจ และเวลา เมื่อยังตรวจไม่ครบจะระบุว่า **ยังไม่ใช่ผลยืนยัน**

บนมือถือที่ยืนยันแล้ว จะแสดงช่องผลผู้เชี่ยวชาญก่อนผล AI เพื่อให้เห็นข้อสรุปก่อน ตารางรายตำแหน่งแสดงว่า AI ทำนายอะไร และผู้เชี่ยวชาญยืนยัน แก้ไข ตัดออก หรือพบเพิ่มเติมอย่างไร ผู้ใช้สลับภาพระหว่างกรอบ AI กับกรอบที่ผู้เชี่ยวชาญยืนยันได้ เมื่อยืนยันครบแล้ว ภาพเริ่มต้นที่กรอบของผู้เชี่ยวชาญ

ข้อความตอบกลับหรือคำขอภาพเพิ่มเติมยังเป็นการสนทนาระหว่างตรวจ การแสดงผลจะไม่แปลงข้อความอิสระเป็นชื่อชนิดที่ยืนยันโดยอัตโนมัติ ผลยืนยันต้องเป็น review ที่มีสถานะ verified ตรวจครบภาพและทบทวนทุกตำแหน่งตามกฎเดิม กรณีผู้เชี่ยวชาญตัดกรอบทั้งหมดออกหรือยืนยันว่าไม่พบวัตถุเป้าหมาย จะแสดงผลยืนยัน 0 ตำแหน่งอย่างชัดเจน

เมื่อเปิดข้อความเก่าจากกระดิ่ง ด้านบนยังคงแสดงผลล่าสุดของรอบส่งต่อนั้น ข้อความที่เลือกอยู่ในส่วนประวัติพร้อมวันที่ ไม่ปะปนกับผลของรอบส่งต่อใหม่

## เปิดคลังภาพของ Super Admin

1. เข้าที่ `/admin/` แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของระบบ
2. เลือก **คลังภาพและผลตรวจ**
3. เลือกบัญชีผู้ส่งหรือค้นหารหัสภาพ กด **วันที่และตัวกรองเพิ่มเติม** เพื่อเลือกวันที่ สถานะ หรือประเภทภาพ
4. เปิดภาพเพื่อดูผู้ส่ง วันเวลา ผล AI เดิม ผลทบทวน คำตอบ และภาพเพิ่มเติม

รายการจัดกลุ่มตามวันและบัญชี แสดงเวลาไทย ใช้การแบ่งหน้าและโหลดภาพตัวอย่างเฉพาะบริเวณที่กำลังดู การโหลดภาพเดิมเข้าคลังทำเป็นชุดเล็กต่อเนื่องและแสดงสถานะระหว่างรวบรวม

## ภาพที่เก็บ

ตามขอบเขตที่ผู้ใช้ยืนยัน คลังเก็บ **ภาพที่กดส่งตรวจและภาพแนบเพิ่มเติม** ทั้งที่ส่งต่อผู้เชี่ยวชาญและไม่ได้ส่งต่อ รวมภาพที่ไม่ผ่านคุณภาพ ภาพที่โมเดลยังไม่พร้อม หรือประมวลผลไม่สำเร็จ หากไฟล์ไม่ใช่ภาพที่ถอดรหัสได้หรือเกินขีดจำกัด ระบบปฏิเสธไฟล์นั้นตามเดิม

การเลือกภาพไว้ดูในเครื่อง ปุ่มตรวจคุณภาพแยก และการแปลงภาพเพื่อแสดงตัวอย่าง ยังไม่สร้างรายการคลังวินิจฉัย ภาพสาธิตไม่ใช่ผลตรวจจริงและไม่เข้าคลังนี้

ภาพแนบเพิ่มเติมเป็นหลักฐานของรายการต้นฉบับ หากยังไม่ได้รันโมเดลบนภาพแนบนั้นโดยเฉพาะ หน้ารายละเอียดจะบอกว่าผล AI/ผู้เชี่ยวชาญเป็นผลของภาพต้นฉบับ ไม่แสดงว่าเป็นผลวิเคราะห์ภาพแนบอย่างอิสระ

## สิทธิ์และการเก็บรักษา

เฉพาะบัญชีที่เป็น Super Admin จริงและได้รับอนุมัติจึงเปิดรายการ รายละเอียด และไฟล์ภาพในคลังได้ บทบาท admin ที่ไม่ใช่เจ้าของ ผู้เชี่ยวชาญ ผู้ใช้ทั่วไป และผู้เยี่ยมชมใช้ API ของคลังไม่ได้ แม้ทราบรหัสภาพ ผู้เชี่ยวชาญยังใช้ภาพและผลในงานตรวจทานตามสิทธิ์เดิมของตนได้

เมื่อผู้ใช้เลือกนำรายการออกจากประวัติ ไฟล์ภาพส่วนใช้งานและรายการในประวัติจะถูกนำออก แต่ **สำเนาภาพและผลยังอยู่ในคลัง Super Admin** หน้ายืนยันการนำออกแจ้งเรื่องนี้อย่างชัดเจน ผล AI เดิมไม่ถูกเขียนทับด้วยคำตอบของผู้เชี่ยวชาญ

ภาพถูกถอดรหัสและเก็บเป็น PNG ที่คงพิกเซลหลังการปรับมาตรฐานเดิม พร้อมล้าง EXIF/GPS/ICC และชื่อไฟล์ต้นทาง สำเนาคลังอยู่ใน `HELPMINTHS_DATA_DIR/archive-images/` นอกเว็บสาธารณะ ใช้สิทธิ์โฟลเดอร์ 0700 และไฟล์ 0600 API รูปภาพไม่ถูกเก็บใน service worker หรือ browser cache

ภาพเดิมที่ยังมีไฟล์อยู่จะนำเข้าคลังย้อนหลังได้ ภาพที่ถูกลบไปแล้วหรือสูญหายจากโฮสต์ก่อนการอัปเดตนี้ จะมีเพียงประวัติเท่าที่เหลืออยู่ ไม่สามารถสร้างไฟล์ต้นฉบับคืนขึ้นมาเองได้

**Render Free ยังใช้พื้นที่ชั่วคราว** การเพิ่มคลังนี้ไม่ได้สร้าง Persistent Disk หรือบริการเก็บข้อมูลถาวร ภาพ บัญชี และผลอาจหายหลัง restart/redeploy หากต้องเก็บย้อนหลังระยะยาว ต้องใช้พื้นที่ถาวรที่ตั้ง `HELPMINTHS_DATA_DIR` ให้ถูกต้อง และสำรองฐานข้อมูลพร้อมทั้ง `images/` และ `archive-images/` อย่างสอดคล้องกัน ZIP สำรองซอร์สโค้ดไม่รวมภาพส่วนตัวเหล่านี้
