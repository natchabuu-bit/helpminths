ฉันต้องการพัฒนาและดูแลเว็บ HelpMinths ต่อจากไฟล์สำรองที่แนบมา
โปรดอ่าน source/docs/backup/RESTORE.th.md, metadata ของชุดสำรอง,
README หลัก และ docs/atlas ก่อนลงมือ ใช้โค้ดที่แนบเป็นต้นฉบับและรักษาไฟล์เดิม
อย่าสร้างแอพใหม่จากศูนย์หรือเดาว่าเว็บไซต์ได้ deploy แล้ว

โครงการนี้เป็นเว็บภาษาไทย โทนเข้ม ใช้งานบนมือถือและคอมพิวเตอร์
ใช้ React/TypeScript/Vite + Three.js/React Three Fiber และ FastAPI/Pillow
มีอัปโหลดภาพหรือเลือกภาพจากกล้อง แสดงกรอบผลตรวจ สาธิตข้อมูลจำลอง
และ Atlas เทียบภาพกล้องจุลทรรศน์กับโมเดล 3D พร้อมซูม หมุน เลือกส่วนประกอบ
คำอธิบายและแหล่งอ้างอิง รองรับสื่อ Atlas/โหมดสาธิตแบบออฟไลน์หลังเตรียมแคชครบ

Atlas มี 12 กลุ่มอ้างอิง:
Ascaris lumbricoides, Trichuris trichiura, Hookworm, Opisthorchis viverrini (OV),
Taenia spp., Enterobius vermicularis, MIF, Hymenolepis nana, H. diminuta,
Echinostoma spp., Fasciolopsis buski และ Strongyloides stercoralis

Strongyloides เป็นตัวอ่อน RHABDITIFORM ไม่ใช่ไข่หรือ filariform
ต้องมี genital primordium ขนาดเด่นชัดภายในลำตัว กดไฮไลต์/โฟกัส/ขยายดูได้
พร้อมช่องปากสั้น หลอดอาหาร rhabditoid และหางแหลม
ตารางเปรียบเทียบใช้ตัวอ่อน rhabditiform ของ Hookworm:
ช่องปากยาวกว่าและ genital primordium เห็นไม่เด่น ไม่ใช่เทียบกับไข่พยาธิปากขอ
ภาพจริง Strongyloides ที่มีใช้ดูรูปร่างโดยรวม ไม่อ้างว่าเห็น genital primordium
ชัดจากภาพเหล่านั้น การเน้นขนาด/สีในโมเดลเป็นภาพอธิบาย ไม่ใช่สเกลวัดจริง

Ascaris เลือกไข่ไม่ปฏิสนธิ ไข่ปฏิสนธิระยะต้น cleavage และ embryonated ได้
สภาพ decorticated เป็นสวิตช์ชั้นผิวนอกหลุด แยกจากระยะพัฒนา
ไข่ไม่ปฏิสนธิไม่พัฒนาต่อเป็นไข่ระยะติดต่อ ภาพนิ่งไม่ยืนยันความมีชีวิต/infectivity
อย่าเปลี่ยนชื่อภาพระยะอื่นเป็น cleavage หรือ decorticated เพื่อให้ดูเหมือนมีภาพจริงครบ

ข้อเท็จจริงที่ต้องรักษา:
- ยังไม่มี trained model weights หรือการยืนยันความแม่นยำ AI ในชุดสำรอง
  API ที่ไม่มีโมเดลต้องรายงานว่าไม่พร้อม/503 ไม่สร้างผลตรวจปลอม
  Atlas เพิ่มชนิดได้โดยไม่ได้แปลว่า detector ตรวจชนิดนั้นได้แล้ว
- โหมดสาธิตต้องติดป้ายชัดว่าเป็นข้อมูลจำลอง ไม่ใช่ผลตรวจ AI
- ยังไม่มีภาพจริง OV/MIF/Echinostoma ที่ตรวจชนิดและสิทธิ์ครบ
  ภาพวาดจำลองต้องติดป้ายและแยกจากภาพกล้องจริง
- ภาพ Buckelew ใช้ CC BY-NC 4.0 เพื่อการศึกษาไม่ใช่เชิงพาณิชย์
  คงเครดิต ใบอนุญาต แหล่งที่มา และตรวจสิทธิ์ก่อนเพิ่มภาพหรือใช้ฝึก AI
- ไม่มีฐานข้อมูลประวัติผู้ใช้บนเซิร์ฟเวอร์ ประวัติ/ภาพอัปโหลดอยู่ในหน่วยความจำหน้าเว็บ
  service worker เก็บเฉพาะไฟล์แอพ ไม่เก็บภาพผู้ใช้หรือผล API ถาวร
- ชื่อผลตรวจและ JSON ต้องคงชื่อ class จากโมเดล ไม่เปลี่ยนชื่อผลเพื่อให้ตรง Atlas
  อย่า map S. fuelleborni/S. ratti เป็น S. stercoralis หรือ Fasciola เป็น Fasciolopsis
