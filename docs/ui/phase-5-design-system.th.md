## Tokens และรูปแบบ

ใช้ `src/styles/tokens.css` เป็นแหล่งกำหนดสี ฟอนต์ ระยะห่าง มุมโค้ง และขนาดปุ่มร่วมกัน

- สีเน้นเดียว `#0d786e` ร่วมกับเทากลางและสีสถานะ success/warning/danger
- ธีมสว่างสำหรับเว็บทั่วไปและธีมเทาเข้มสำหรับหลังบ้านผ่าน `html[data-theme]` หลังบ้านใช้สีเน้นเดียวกัน โดยสีข้อความ/โฟกัสปรับให้คอนทราสต์พอบนพื้นเข้ม
- ฟอนต์ Noto Sans Thai สำหรับภาษาไทยและอักษรละติน รวมถึงข้อความ code ใน UI ยกเลิก import และ dependency ของ Inter
- มุมโค้งสำหรับ UI ใช้ 8px/12px และใช้ 50% เฉพาะรูปวงกลม
- ระยะ padding/margin/gap ใช้ scale 8px ผ่านตัวแปร ส่วนกรอบ เส้น ไอคอน ภาพ และตัวช่วยอ่านหน้าจอมีค่าขนาดตามหน้าที่ ตัวช่วยอ่านหน้าจอเดิมยังใช้ geometry 1px โดยอ้าง token และไม่เปลี่ยนพฤติกรรมการซ่อน
- พื้นที่กดของปุ่มควบคุม HTML ขั้นต่ำ 44px หลายกลุ่มใช้ 48px
- ลบ gradient และ backdrop-filter จาก CSS ทั้งหมด ใช้พื้นทึบและ overlay สีเทา
- ไม่มีค่า hex/rgb/hsl โดยตรงนอกไฟล์ tokens ใน `src/styles`

คงสีของภาพจริง ภาพวาดอธิบาย กรอบวัตถุบนภาพ และโมเดล 3D ตามเดิม สีเหล่านี้เป็นเนื้อหาอ้างอิงหรือข้อมูลวัตถุ ไม่ใช่ชุดสีตกแต่งของ UI ข้อความในรายการผลตรวจใช้สีจาก tokens

## รวม CSS

จาก 26 ไฟล์ใน `src/styles` และ 2 ไฟล์ของหลังบ้าน เหลือ CSS ร่วมกัน 9 ไฟล์:

| ไฟล์ | หน้าที่ |
| --- | --- |
| `tokens.css` | สี ฟอนต์ ระยะ มุมโค้ง ขนาดควบคุม และธีม |
| `app.css` | Base, shell, navigation, home และรูปแบบร่วม |
| `platform.css` | หน้าข้อมูล ประวัติ ทบทวน คุณภาพภาพ และการเปรียบเทียบผล |
| `account.css` | บัญชี เมนูอวาตาร์ รหัสผ่าน การแจ้งเตือน และจัดการสมาชิก |
| `scan.css` | หน้าตรวจและ workflow |
| `atlas.css` | Atlas และคู่มือระยะ Ascaris/Strongyloides |
| `dashboard.css` | สถิติโรคและข้อมูลย้อนหลัง |
| `evaluation.css` | SUS และ feedback |
| `backoffice.css` | เว็บหลังบ้านและคลังภาพ |

เปลี่ยน imports ตามไฟล์ใหม่ ลบไฟล์ที่รวมแล้ว ลดประกาศซ้ำที่ใช้ selector/context เดียวกันโดยรักษา responsive และลำดับ cascade ที่ยังจำเป็น

## กราฟและข้อมูล

กราฟทั่วไปใช้สีเน้นและเทา พร้อมเส้นประ/legend แยกชุดข้อมูล แถบความชุกและ heatmap ใช้คู่สีสถานะที่อ่านข้อความได้ คงค่าข้อมูล ขอบเขตการแบ่งช่วง เกณฑ์ การเรียง การกรอง และ API เดิมทั้งหมด

## การตรวจและ tests

เพิ่ม `npm run test:design-system` เพื่อตรวจ CSS ด้วย PostCSS และวัดสี/ขนาดที่เบราว์เซอร์แสดงจริงในหน้าทั่วไป บัญชีสมาชิก และหลังบ้าน ทั้ง 375px และ 1440px ใช้ fixtures อ่านอย่างเดียวและไม่เขียนข้อมูลจริง

การวัดครอบคลุม HTML UI ปกติ ไม่รวมสีภายใน SVG/canvas ทางวิชาการ จุด annotation ที่ต้องตรงตำแหน่งวัตถุ และสถานะควบคุมที่ปิดใช้งานซึ่งได้รับยกเว้นตามเกณฑ์คอนทราสต์ พื้นที่กดที่รายงานเป็นปุ่ม/ลิงก์/summary ของ UI ไม่ใช่ขนาดกรอบวัตถุบนภาพ

- ผลวัดบน 36 หน้าจอ: ข้อความ 2,547 รายการ พื้นที่กด 614 จุด คอนทราสต์ต่ำสุด **4.69:1** และพื้นที่กดต่ำสุด **44px**
- คู่สีใน tokens ตรวจได้อย่างน้อย **4.57:1** รวมคู่สีในธีมเข้ม; สีขาวบนสีเน้น **5.35:1**
- ตรวจภาพหน้าแรก Scan Atlas modal และหลังบ้านจริง ไม่มี browser error หรือเนื้อหาล้นในตัวอย่างมือถือ/เดสก์ท็อปที่ตรวจ
