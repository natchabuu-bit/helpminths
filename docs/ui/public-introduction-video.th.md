# วิดีโอแนะนำ HelpMinths แบบสาธารณะ

วันที่ตรวจ: 14 พฤศจิกายน 2569

หน้าแรกมีส่วนพับ **ดูวิดีโอแนะนำ (30 วินาที)** อยู่ใต้ปุ่มเริ่มตรวจและข้อความทบทวนโดยผู้เชี่ยวชาญ ผู้เยี่ยมชมกดดูได้โดยไม่ต้องมีบัญชี หน้าแรกยังมี 3 ส่วนและปุ่มหลักเดิม 2 ปุ่ม

เครื่องเล่นใช้ controls ของเบราว์เซอร์ มี playsInline สำหรับมือถือ ภาพปก คำบรรยายไทย เนื้อหาแบบข้อความ และเครดิตภาพ/ดนตรี ไม่เล่นอัตโนมัติและไม่โหลด MP4 จนกดเล่น เมื่อพับส่วนวิดีโอจะถอดเครื่องเล่นเพื่อหยุดภาพและเสียง

ไฟล์ MP4 ต้นฉบับ 1920×1080, H.264/AAC, 30.000 วินาที อยู่ใน `public/media/` และถูกคัดลอกเข้า `dist/media/` ตาม Vite build เดิม การให้บริการไฟล์สาธารณะใช้ StaticFiles เดิม ไม่แก้ backend, model, Atlas หรือกฎสิทธิ์ใด ๆ

ตัด MP4 ออกจากรายการ offline precache เพื่อไม่บังคับโหลดวิดีโอเมื่อเปิดหน้าแรก และให้ byte-range streaming ไปยัง static server โดยตรง ภาพปก คำบรรยาย และเครดิตยังอยู่ในชุดไฟล์ขนาดเล็กที่เตรียมออฟไลน์

## ผลตรวจ

- `npm run typecheck`: ผ่าน
- `npm run build`: ผ่าน
- `npm run test:interface`: ผ่าน 12/12
- `npm run test:e2e`: ผ่าน 14/14
- `npm run test:offline`: ผ่าน 3/3
- ทดสอบ Chromium ที่ 320/375/1440px: ผู้เยี่ยมชมเล่นวิดีโอได้ครบความยาว 30 วินาที เลื่อนช่วงได้ คำบรรยายโหลดครบ 8 ช่วง และหน้าไม่ล้น
- ยืนยัน HTTP 200 ของ MP4/ภาพปก/คำบรรยายโดยไม่มี session และ HTTP 206 สำหรับช่วง bytes=0-1023
- ทดสอบหลัง service worker ควบคุมหน้าแล้ว: วิดีโอเล่นและเลื่อนช่วงได้ คำขอ MP4 ได้ 206 จากเซิร์ฟเวอร์และไม่ผ่าน service worker
- ทดสอบการโหลด MP4 ล้มเหลว: มีข้อความช่วยเหลือและลิงก์เปิดวิดีโอโดยตรง
- ภาพวิดีโอเป็นข้อมูลสาธิต ไม่ใช้ข้อมูลบัญชีหรือภาพผู้ป่วยจาก production และคงข้อความทบทวนโดยผู้เชี่ยวชาญพร้อมเครดิตภาพ

ปรับ assertion ใน interface test ให้นับปุ่มหลักภายใน `.field-actions` แทนการนับปุ่มทั้งหมดในส่วนแนะนำ เพราะส่วนพับวิดีโอเป็นตัวควบคุมเพิ่มเติม เพิ่มการตรวจเล่น/seek/คำบรรยาย/สิทธิ์ผู้เยี่ยมชม และตรวจว่า MP4 ไม่อยู่ใน offline cache โดยคงข้อกำหนดหน้าแรก 3 ส่วนและปุ่มหลัก 2 ปุ่มเดิม

## เผยแพร่

ไฟล์ `render.yaml` ปัจจุบันกำหนด `autoDeploy: false` หลังนำ commit เข้า `main` ให้เปิด Render → บริการ helpminths → Manual Deploy → Deploy latest commit ไม่ต้องเพิ่ม Environment หรือฐานข้อมูลเพื่อแสดงวิดีโอนี้
