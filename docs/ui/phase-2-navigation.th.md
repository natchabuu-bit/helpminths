# เฟส 2: เมนูและงานของฉัน

- Branch: `ui/phase-2-navigation`
- แยกจากเฟส 1 ที่ commit `379bd31` บน `ui/phase-1-cleanup-audit`
- ขอบเขต: เปลี่ยนการนำทางและจัดหน้ารายการงาน โดยใช้ session และ API เดิม

## การใช้งานที่เปลี่ยน

1. เมนูหลักเหลือ **ตรวจวิเคราะห์ · Atlas 3D · สถิติโรค · งานของฉัน** เปลี่ยนชื่อ Dashboard เป็นสถิติโรค โดยคงหน้าสถิติและข้อมูลเดิม
2. เดสก์ท็อปใช้เมนูด้านบน มือถือและแท็บเล็ตจอแคบกว่า 1024px ใช้แท็บล่างสี่รายการ มีพื้นที่เผื่อเนื้อหาและ safe area
3. กลุ่ม **จัดการ** รวมทบทวนโดยผู้เชี่ยวชาญ รายงาน และประเมินโมเดล แสดงเฉพาะ session ที่พร้อมใช้งาน บัญชี active อนุมัติแล้ว และ role `admin/reviewer/lab` หน้าเหล่านี้ตรวจ session ก่อน mount เช่นกัน สิทธิ์และขั้นยืนยันผู้เชี่ยวชาญฝั่งเซิร์ฟเวอร์คงเดิม
4. **ตั้งค่าและบัญชี** เปิดจากเมนูอวาตาร์เท่านั้น คู่มือมีปุ่มเดียวบนส่วนหัว และ **ประเมินและเสนอแนะ** เปิด SUS จาก footer โดยเอาแท็บ SUS ที่ซ้ำในหน้าประเมินโมเดลออก
5. **งานของฉัน** รวมประวัติที่บันทึกไว้และผลในเซสชันนี้เป็นสองแท็บ ใช้ประวัติส่วนตัวเดิมพร้อมตัวกรองวันและสถานะส่งต่อ ไม่คัดลอกข้อมูลส่วนตัวไปเก็บในแท็บผลชั่วคราว ล้างรายการและแท็บที่เลือกเมื่อเปลี่ยนบัญชี ลิงก์ `#history` เดิมเปลี่ยนเป็น `#work`
6. หน้าภาพรวมยังเปิดได้จากโลโก้ HelpMinths โดยไม่เพิ่มเมนูหลักรายการที่ห้า

## การเข้าถึงและขอบเขตที่คงไว้

- เก็บ skip link, `focus-visible`, `aria-current`, focus trap และการคืนโฟกัสของ modal คู่มือ
- เมนูจัดการรองรับคีย์บอร์ด ลูกศร Home/End และ Escape คืนโฟกัสให้ปุ่มจัดการเมื่อเลือกปลายทาง
- แท็บงานรองรับคีย์บอร์ดและเชื่อม tab/tabpanel ด้วย ARIA
- คง `prefers-reduced-motion` รวมถึงการเลื่อนหน้า และข้อความ **ผล AI ต้องได้รับการทบทวนโดยผู้เชี่ยวชาญ**
- ไม่มีการแก้ `backend/`, `models/`, `public/atlas/`, `src/platform/api.ts` หรือ `src/components/AtlasModel.tsx`

## Tests ที่ปรับตามการนำทาง

- `tests/interface.test.mjs`: เปลี่ยนจาก sidebar เป็นเมนูหลักสี่รายการ เพิ่มขนาดจอ สิทธิ์จัดการ การเข้าหน้าจาก URL เมนูอวาตาร์ คู่มือ คีย์บอร์ด และการล้างข้อมูลเมื่อ session สิ้นสุด
- `tests/e2e.test.mjs`: ใช้ชื่อสถิติโรคและงานของฉัน เลือกแท็บผลในเซสชันนี้ และใช้โลโก้กลับภาพรวม เก็บ assertions ของโมเดล ภาพ anatomy และ morphology เดิม
- เพิ่ม `tests/helpers/navigation.mjs` และปรับเส้นทางใน suites `platform`, `referrals`, `admin-dashboard`, `feedback`, `health-dashboard`, `account-readiness`, `offline` ให้ใช้เมนูหลัก เมนูจัดการ อวาตาร์ และ footer ตามหน้าใหม่
- `platform`: ปรับตัวระบุภาพแบบอ่านอย่างเดียวของบัญชี lab ให้ตรงกับชื่อที่แสดงจริง ตรวจชื่อวัตถุในกรอบ และยืนยันว่าไม่มี editor; ปรับ guest/expired session ให้ตรวจการซ่อนสถิติส่วนตัวและการกลับสู่เมนูบัญชี โดยคง assertions ของสิทธิ์และผลตรวจทั้งหมด
- ปรับ `scripts/capture-interface.mjs` ให้เปิดเมนูและชื่อสถิติโรคใหม่
- ไม่มีการลดเงื่อนไขตรวจสิทธิ์ฝั่ง API หรือเปลี่ยนผลตรวจทางชีววิทยาเพื่อให้ tests ผ่าน
