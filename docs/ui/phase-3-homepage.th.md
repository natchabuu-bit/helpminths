## หน้าแรก

เหลือเนื้อหาหลักสามส่วนตามลำดับ:

1. ส่วนแนะนำ: หัวข้อ “ตรวจภาพไข่พยาธิ” หนึ่งบรรทัดที่ขนาดข้อความปกติ คำอธิบายหนึ่งประโยค ปุ่ม **เริ่มตรวจวิเคราะห์** และ **ดูตัวอย่าง** พร้อมข้อความ **ผล AI ต้องได้รับการทบทวนโดยผู้เชี่ยวชาญ** เป็นข้อความสั้นใต้ปุ่ม
2. ขั้นตอนการใช้งานสามขั้น: เพิ่มภาพ สำรวจผล และเรียนรู้ผ่าน Atlas
3. ตัวอย่าง Atlas สามกลุ่ม พร้อมทางเข้าสำรวจทั้งหมด

เอา capability-strip, กล่องเชิญ feedback, แผงโมเดลและข้อมูลซ้ำบนหน้าแรก รวมถึงปุ่มเริ่มตรวจที่ซ้ำออก การหมุน ซูม และสำรวจโครงสร้างยังใช้งานใน Atlas 3D ไม่มีการแก้โมเดล

ย้าย PlatformDashboard ไปที่ **จัดการ → รายงาน → ภาพรวมการดำเนินงาน** ในส่วนที่กดขยายได้ ใช้ session/สิทธิ์เดิม และเริ่มโหลดข้อมูลเมื่อเปิดส่วนนี้ หัวข้อภาพรวมใช้ h2 เพื่อคง h1 ของหน้ารายงานไว้เพียงหนึ่งหัวข้อ

ถอดการเช็กสถานะโมเดลเป็นระยะของหน้าแรกที่ไม่มีส่วนแสดงแล้ว หน้าตรวจวิเคราะห์ยังตรวจความพร้อมด้วย logic เดิม

## ข้อความและรูปแบบ

- เอาคำโปรยอังกฤษ ตัวเลข SPECIMEN และป้ายตกแต่งในหน้าแรก Scan และ Atlas ออก รวมถึงหัวข้อประดับของคู่มือระยะ Ascaris/Strongyloides และ kicker ในหัวข้อหน้าทั่วไป
- คงชื่อวิทยาศาสตร์ ศัพท์โครงสร้าง ชื่อ Atlas 3D หน่วยวัด คำเตือนไม่ใช่สเกลจริง และข้อความที่ระบุว่าภาพสาธิตเป็นภาพสังเคราะห์
- ลบ CSS ของ capability-strip/icon, feedback-invite, กล่อง research-note เดิม และ specimen-number โดยคง selectors อื่น
- หัวข้อและปุ่มยอมให้ตัดบรรทัดเมื่อขยายข้อความ เพื่อไม่บังคับซ่อนเนื้อหาหรือล้นจอบนมือถือ
- คง skip link, focus-visible, aria-current, focus trap ของ modal, reduced motion และข้อความเตือนตามที่กำหนด

## Tests ที่ปรับ

- `tests/interface.test.mjs`: เปลี่ยน tests ของแผงโมเดลบนหน้าแรกที่นำออก เป็นการตรวจโครงสร้างสามส่วน หัวข้อและปุ่มจริงในห้าขนาดจอ เส้นทางอัปโหลด/สาธิต/Atlas และการไม่มีข้อความหรือปุ่มตกแต่งที่ยกเลิก
- เพิ่มการตรวจว่าหน้าแรกของ guest/student/lab/reviewer/admin ไม่โหลดข้อมูลการดำเนินงานหรือข้อมูลผลตรวจ และส่วนภาพรวมในรายงานโหลดเมื่อกดขยายเท่านั้น
- คง tests เมนู สิทธิ์ การเข้าถึงด้วยคีย์บอร์ด focus trap และการแยกข้อมูลแต่ละบัญชี
- `tests/e2e.test.mjs` ไม่เปลี่ยน: คง assertions ของการวิเคราะห์ morphology โมเดล 3D ภาพจริง ระยะ Ascaris และ Strongyloides ทั้งหมด
- `scripts/capture-interface.mjs`: รอหัวข้อหน้าแรกแทน canvas ของแผงโมเดลเดิม
