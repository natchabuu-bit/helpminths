## ผลตรวจชุดสำรอง

ตรวจ CRC ของ ZIP และ SHA-256 หลังแตกไฟล์ครบ 121 รายการผ่านแล้ว
Git bundle clone ได้ประวัติครบและ HEAD ตรง metadata โค้ดที่กู้คืน build ได้
โดยใช้ dependencies เดิมที่ตรวจแล้ว ผล build ทั้ง 34 ไฟล์ตรงกับเว็บในชุดสำรอง
ทุกไบต์ เว็บ/API และภาพทั้ง 11 ภาพตอบ HTTP 200 จากโฟลเดอร์กู้คืน
การตรวจนี้ใช้ runtime ที่ติดตั้งไว้แล้ว ไม่ใช่การติดตั้งใหม่จากอินเทอร์เน็ต

เปิด `production-web/` ที่แตกจาก ZIP ด้วยเว็บเซิร์ฟเวอร์แบบ static แล้วทดสอบ
เบราว์เซอร์ซ้ำผ่าน: บันทึกภาพ 11 ภาพตั้งแต่หน้าแรก เปิด Atlas 12 กลุ่ม
เลือกและขยาย genital primordium เปลี่ยนระยะ Ascaris/decorticated และเปิดโหมด
สาธิตขณะออฟไลน์ได้ โดยไม่พบ browser exceptions

โค้ดรุ่นนี้ผ่าน E2E 14/14 และ offline 2/2 ไม่มีรายการที่ข้าม
ชุดสำรองไม่มี trained weights, notebook ต้นฉบับที่ยังนำเข้าพื้นที่งานไม่ได้,
รหัสผ่านผู้ให้บริการ หรือข้อมูลอัปโหลด/ประวัติที่อยู่เฉพาะในหน่วยความจำของหน้าเว็บ
